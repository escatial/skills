# conf-papers 技能文档

## 技能概述

**功能**：搜索学术论文，支持中文核心期刊、中文硕士论文、英文期刊/顶会，覆盖所有学科领域。

**核心原则**：
- 所有论文数据必须来自真实搜索，禁止自行生成
- 搜索结果必须附带原文链接或 PDF 地址
- 优先使用 WebSearch 实时搜索
- **支持所有学科**：管理学、教育学、AI、农学、医学、工学等

---

## 文献类型与搜索策略

### 1. 中文核心期刊（40%）
- CSSCI：《管理世界》《教育研究》《统计研究》《计算机学报》等
- CSCD：各学科核心期刊
- 北大核心：各学科中文核心期刊
- 搜索Query：`site:cnki.net "CSSCI" + 主题词` 或直接搜索

### 2. 中文硕士论文（40%）
- CNKI 硕士论文库：优先"985/211"高校
- 研究框架规范、文献综述完整的论文
- 搜索Query：`硕士论文 + 主题词 + site:cnki.net`

### 3. 英文期刊/顶会（20%）
- 顶会：CVPR/ICCV/ECCV/ICLR/AAAI/NeurIPS/ICML/SIGKDD 等
- 英文期刊：Nature/Science 子刊、IEEE Trans 系列、Springer/Lemma 等
- 搜索Query：`主题词 + site:arxiv.org` 或 `主题词 + conference`

---

## 使用方式

```
/conf-papers <关键词> [文献类型]
```

**参数**：
- `<关键词>`：搜索主题（如 "水产品营销"、"企业数字化转型"）
- `[文献类型]`：可选，`期刊` | `硕士论文` | `顶会` | `全部`，默认全部

**示例**：
```
/conf-papers 水产品营销策略
/conf-papers 企业战略 硕士论文
/conf-papers 机器学习 顶会
/conf-papers 教育评估 期刊
```

---

## 输出格式

搜索结果按文献类型分组呈现：

### 中文核心期刊
- 论文标题、作者、期刊名、年份
- 摘要（原文，非生成）
- 原文链接
- 适用场景说明

### 中文硕士论文
- 论文标题、作者、学校、年份
- 研究框架/方法论摘要
- 原文链接
- **结构参考价值说明**（适合借鉴的章节）

### 英文期刊/顶会
- 论文标题、作者、会议/期刊、年份
- 摘要（原文）
- 原文链接

---

## 防幻觉措施

1. 搜索使用 `mcp__MiniMax__web_search` 实时查询
2. 摘要提取使用 WebSearch 获取论文页面内容
3. 所有链接必须可访问，禁止使用占位链接
4. 无法确认真实性的信息标注"（来源待验证）"
5. **中文硕士论文不生成摘要，仅提取结构框架信息**
