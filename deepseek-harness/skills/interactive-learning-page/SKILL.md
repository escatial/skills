# 交互式学习页面（interactive-learning-page）

## 什么时候用

用户请求**学习类产出**时必须用本 skill，不要只回纯文本。触发场景：

- 「教我 / 带我学 XX」「我想学 XX，帮我制定计划」
- 「把 XX 拆成学习阶梯」「帮我筛 XX 的学习资源」
- 「当我的考官考我 XX」「把刚学的内容整理成速查表」
- 任何以「学习」为目的的长篇知识产出

学习友好 = 主动回忆（自测、翻卡）+ 进度可视（打卡、阶梯定位），而不是被动阅读大段文字。

## 主题与内容来源（最重要）

- **主题 = 用户请求里的 XX**。用户说「教我学 Rust」，页面就是 Rust 的学习页；说「考我线性代数」，自测题全是线代题。**不存在通用页面**——参考实现只是结构示范，不是内容。
- 请求里**没有主题**时（如只说「带我学」），先问一句「你想学什么？」再生成，不要自作主张选主题。
- 所有内容必须为该主题**现场定制**：
  - 学习阶梯 = 该主题从入门到精通的 5 个真实阶段
  - 方法提示词 = 「如何用 AI 学**这个主题**」的具体可复制 prompt（含主题关键词，不是 `<主题>` 占位符）
  - 自测题 = 考该主题的**真实知识点**（答错解析要讲知识点本身）
  - 翻卡 = 该主题的核心概念/术语/易错点
- 页面 `<title>`、顶部标题、进度条文案都要体现主题名；localStorage key 用 `ilp_<主题slug>_v1`。

## 硬性产出要求

1. **单文件 HTML**：所有 CSS / JS 内联，无外部依赖、无 CDN、无网络请求，双击即可用浏览器打开。
2. **中文界面**，移动端可读（viewport + 响应式）。
3. **localStorage 持久化**：勾选/答题/自评状态存一个版本化 key（如 `ilp_<topic>_v1`），刷新不丢，并提供「清空进度」按钮。
4. 完成后在回复里给出**文件路径**和一句话使用说明（数据只存本地浏览器）。

## 页面必备模块（对应学习方法论 7 步）

| 模块 | 交互形式 | 对应方法 |
|---|---|---|
| 学习阶梯自评 | L1–L5 可点选定位，标注每层该用哪些方法 | 01 阶梯 |
| 方法卡片 | 可折叠；每张含「为什么 / 提示词模板 / 要点」 | 01–07 |
| 提示词一键复制 | 复制按钮 + clipboard API + execCommand 兜底 | 01–07 |
| 自测题 | 每模块 2 题选择题，点击即时判对错并展开解析；做对才算过关 | 05 考官 |
| 打卡进度条 | 「我已学完这一块」勾选 → 顶部进度条 x/7 | 04 执行 |
| 速查表翻卡 | 3D 翻转卡（正面模块名，背面一句话核心），考前唤醒 | 06 速查表 |

可选：费曼复述区（textarea 让用户用自己的话写一遍，写完可让 AI 批改）。

## 参考实现

完整可抄的参考实现见：
`https://github.com/escatial/ai-learning-playbook`（index.html，AI 学习法 7 方法交互版）。
结构要点：`METHODS` / `CARDS` 数据数组驱动渲染 → DOM 全部 JS 生成 → 状态对象 `{done, quiz, lv}` 存 localStorage → `refresh()` 统一刷进度条与卡片完成态。
