## 常见写作错误

| 错误 | 后果 |
|---|---|
| 只报 CFI 和 RMSEA，不报 SRMR/TLI | 被要求补充 |
| 因为 χ² 显著就说"模型不成立" | 统计理解错误 |
| 中介用 Sobel 检验 | 方法过时 |
| 中介只报 p 值不报 CI | Bootstrap 的意义就在 CI |
| 不报告 Bootstrap 抽样次数 | 不可复现 |
| 隐瞒模型修正过程 | 学术诚信问题 |
| 跑了 5 个模型只报最好的那个 | 学术不端 |
| 阈值不引文献 | "为什么是 .50 不是 .40？" |
