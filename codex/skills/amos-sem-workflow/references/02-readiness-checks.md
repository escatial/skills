# 达标预检验：进 AMOS 之前必须过的 8 道关

> **核心原则：把关口前移。** 数据不达标就进 AMOS，你只会得到不收敛的模型、负误差方差和永远修不好的拟合指标——然后被迫用修正指数把模型硬拗出来，被审稿人一眼看穿。

每一关都给出：**判定标准 → 怎么算 → 不达标怎么办**。

---

## 关卡 1 · 样本量

### 判定
- **绝对量**：N ≥ 200（SEM 的常见下限）
- **相对量（更重要）**：**N : 待估参数 ≥ 5 : 1**，理想 **10 : 1**（Bentler & Chou, 1987）
- 模型越复杂，需要的样本越多

### 怎么数"待估参数"
自由估计的载荷 + 路径系数 + 误差方差 + 协方差。
（一个 3 因子 × 4 指标的 CFA，大约 30 个参数 → 至少需要 150~300 人）

### 不达标
- 继续收数据
- **简化模型**：用打包法（item parceling）把题项打包成 2-3 个指标
- 分步验证：先分别做各维度的 CFA

---

## 关卡 2 · 缺失值

### 判定
- 缺失 **< 5%** → 影响较小
- 关键是**缺失机制**：做 **Little's MCAR 检验**（p > .05 → 完全随机缺失，可放心处理）

### 处理
| 缺失情况 | 处理 |
|---|---|
| < 5% 且 MCAR | 均值替换 / EM / 直接删除 |
| 5-15% | **EM 算法** 或 **多重插补** |
| MAR/MNAR | **FIML**（AMOS 支持：Estimate means and intercepts） |
| 某题缺失 > 20% | 考虑删除该题 |

> ⚠️ AMOS 用 FIML 处理缺失时，**无法输出部分拟合指标**（如 GFI、RMSEA 需要额外设置）。事先想清楚。

### SPSS
`分析 → 缺失值分析 → 勾选 EM` → 输出含 Little's MCAR

---

## 关卡 3 · 异常值

### 单变量
标准化后 **|z| > 3.29**（p < .001）

### 多变量（SEM 必做）
**Mahalanobis D²**：
- SPSS：`分析 → 回归 → 线性`，把 ID 作因变量、所有观测变量作自变量 → 保存 → 勾选 **马氏距离**
- 判定：`CDF.CHISQ(MAH_1, df)` 的 p **< .001** → 多变量异常值
- df = 观测变量个数

### 处理
- **不要无脑删**。先核查是不是录入错误、规律作答。
- 删除必须**报告数量与理由**。
- 删除比例过大（> 5%）说明数据质量本身有问题。

---

## 关卡 4 · 正态性

SEM 的默认估计法 **ML 假设多元正态**。

### 判定（Kline, 2016）
- **|偏度 Skewness| < 3**（严格些用 < 2）
- **|峰度 Kurtosis| < 8**（严格些用 < 7）
- 多元正态：**Mardia 多元峰度系数**（AMOS 输出中有）

### 不达标
| 程度 | 对策 |
|---|---|
| 轻微偏离 | ML 稳健，可继续 |
| 中度偏离 | **Bootstrap ML**（AMOS：Analysis Properties → Bootstrap → 勾选 Bootstrap ML） |
| 严重偏离 | 数据转换；或改用 **ADF/WLS**（需大样本）；或用 Mplus 的 MLR |
| 类别型/李克特 5 点以下 | 考虑用**多分相关矩阵 + WLSMV**（AMOS 支持有限，可换 Mplus/lavaan） |

> **重要**：非正态最常见的后果是 **χ² 被高估、标准误被低估** → 显著性被夸大。用 Bootstrap 可以修正。

---

## 关卡 5 · 共同方法偏差（CMB）

同一份问卷、同一时间、同一被试自评 → **必须检验**。

### 方法 A：Harman 单因子检验（最低要求）
- 把所有题项做 **未旋转的 EFA**
- 判定：**第一个因子解释的方差 < 40%**（有的领域用 50%）
- 局限：这是个很宽松的检验，只能作为初步证据

### 方法 B：潜在共同方法因子 CLF（更有说服力）
- 在 CFA 中加入一个共同方法潜因子，让所有题项同时载荷其上
- 比较加入前后的**标准化载荷变化**
- 判定：变化 **< 0.2** → 共同方法偏差不严重

### 方法 C：事前控制（最好）
- 匿名作答、反向题、不同来源的数据、时间分离

### 不达标
说明存在严重共同方法偏差 → 必须在局限中说明，或用 CLF 控制后再估计。

---

## 关卡 6 · 信度

### Cronbach's α
- **α ≥ .70** 可接受；≥ .80 良好
- 探索性研究可放宽到 .60
- **α > .95** 反而要警惕：题项冗余

### 题总相关 CITC
- **CITC ≥ .30**；低于 .30 考虑删题
- 看"删除该项后的 α"是否显著上升

### 组合信度 CR（CFA 之后算）
```
CR = (Σ标准化载荷)² / [ (Σ标准化载荷)² + Σ误差方差 ]
其中 误差方差 = 1 − 标准化载荷²
```
- **CR ≥ .70**

> CR 比 α 更适合 SEM，因为它不假设所有题项等权重。**两个都报。**

---

## 关卡 7 · 效度

### EFA 适合性（做 EFA 前）
- **KMO ≥ .70**（≥ .80 良好；< .60 不适合）
- **Bartlett 球形检验 p < .001**

### 收敛效度（Convergent Validity）
| 指标 | 标准 |
|---|---|
| 标准化因子载荷 | **≥ .50**，最好 **≥ .70** |
| **CR 组合信度** | **≥ .70** |
| **AVE 平均方差抽取** | **≥ .50** |

```
AVE = Σ(标准化载荷²) / 题项数
```

> AVE ≥ .50 意味着：该构念解释的方差 > 误差方差。
> 若 AVE 在 .40~.50 之间但 CR > .70，部分文献认为仍可接受（Fornell & Larcker, 1981）——**但要引文献说明**。

### 区分效度（Discriminant Validity）

**方法 1：Fornell-Larcker 准则**
- **√AVE > 该因子与任何其他因子的相关系数**
- 做成一张表：对角线放 √AVE，下三角放因子间相关

**方法 2：HTMT（更严格，近年更被接受）**
- **HTMT < .85**（严格）或 **< .90**（宽松）

### 不达标
- 载荷 < .50 → **删题**（但每个因子至少保留 3 个指标）
- AVE < .50 → 删低载荷题项；或重新界定构念
- 区分效度不过 → 两个因子可能是同一个东西 → **合并**，或重新审视理论

---

## 关卡 8 · 多重共线性

- **VIF < 5**（严格）或 < 10（宽松）
- **因子间相关 < .85**（超过说明构念高度重叠）
- 若结构模型中自变量高度相关 → 路径系数会不稳定甚至符号反转

---

## 一张表：全部标准速查

| 检验 | 指标 | 标准 |
|---|---|---|
| 样本量 | N / N:p | ≥ 200 / ≥ 5:1 |
| 缺失 | 比例 / Little's MCAR | < 5% / p > .05 |
| 异常值 | Mahalanobis D² | p ≥ .001 |
| 正态 | 偏度 / 峰度 | \|S\| < 3 / \|K\| < 8 |
| CMB | Harman 第一因子 | < 40% |
| 信度 | α / CR | ≥ .70 / ≥ .70 |
| EFA | KMO / Bartlett | ≥ .70 / p < .001 |
| 收敛效度 | 载荷 / AVE | ≥ .50 / ≥ .50 |
| 区分效度 | √AVE vs r / HTMT | √AVE > r / < .85 |
| 共线性 | VIF / 因子相关 | < 5 / < .85 |

## Python 快速预检验（可选）

```python
import pandas as pd, numpy as np
from scipy import stats

df = pd.read_spss("data.sav")   # 或 read_csv

# 偏度峰度
desc = pd.DataFrame({
    "skew": df.skew(),
    "kurtosis": df.kurtosis()   # 注意：pandas 给的是超额峰度
})
print(desc[(desc.skew.abs() > 3) | (desc.kurtosis.abs() > 8)])

# Cronbach's α
def cronbach_alpha(X):
    X = X.dropna()
    k = X.shape[1]
    return k / (k - 1) * (1 - X.var(ddof=1).sum() / X.sum(axis=1).var(ddof=1))

# Mahalanobis
X = df[items].dropna()
mu, S_inv = X.mean().values, np.linalg.inv(np.cov(X.T))
d2 = np.array([ (r-mu) @ S_inv @ (r-mu) for r in X.values ])
p = 1 - stats.chi2.cdf(d2, df=X.shape[1])
print("多变量异常值数量:", (p < .001).sum())

# AVE / CR（需先有标准化载荷 loadings）
def ave_cr(loadings):
    l = np.array(loadings)
    ave = (l**2).mean()
    cr = l.sum()**2 / (l.sum()**2 + (1 - l**2).sum())
    return ave, cr
```

## 决策规则

> **任何一关不达标 → 回去修数据或修量表，不要进 AMOS。**
>
> 进了 AMOS 再用修正指数救，是最糟糕的选择：
> 你会得到一个拟合很好、但完全没有理论支撑、且无法复现的模型。
