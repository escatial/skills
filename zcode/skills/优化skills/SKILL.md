# Skill创建者

用于创建新skills并迭代改进它们的skill。

高层次来看，创建skill的过程如下：

- 决定你想要skill做什么以及大致应该如何做
- 起草skill
- 创建一些测试提示并用claude-with-access-to-the-skill运行它们
- 帮助用户定性和定量地评估结果
- 根据用户对结果的评估反馈重写skill（如果基准测试中有任何明显缺陷也要考虑）
- 重复直到满意
- 扩展测试集并更大规模地尝试

使用此skill时，您的工作是找出用户在这个过程中的位置，然后帮助他们完成这些阶段。例如，可能他们说"我想为X创建一个skill"。你可以帮助缩小他们的意思，写一个草案，写测试用例，找出他们想要如何评估，运行所有提示，并重复。

另一方面，也许他们已经有一个skill的草案。在这种情况下，你可以直接进入评估/迭代循环。

当然，你应该保持灵活性，如果用户说"我不需要运行一堆评估，只管和我一起感觉"，你可以这样做。

然后在skill完成后（但顺序是灵活的），你也可以运行skill描述改进器，我们有一个单独的脚本，用于优化skill的触发。
