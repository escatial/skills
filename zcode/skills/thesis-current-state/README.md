# thesis-current-state Skill

论文「“公司现状”“企业现状”」章节写作助手。适用于硕士、博士、MBA、期刊论文中"现状描述/现状分析"章节的统一写作工作流。

## 一句话说明

把论文"现状"章节的共性写作模式固化为可复用工作流。用户只需给基本信息（研究对象 + 主题 + 关键事实 + 是否匿名 + 论文类型），skill 自动套用结构、学术规范、质量保证。

    └── 质量自检报告.md                   # 配套质量报告示例

## 触发词

- 写"现状""现状分析""现状描述""公司现状""业务现状""生产现状""管理现状""技术现状""行业现状""市场现状"等
- 描述现状、研究对象现状、current state、现状章节

## 不适用

- 纯文献综述（用 `literature-review` / `academic-deep-research`）
- 问题诊断（Why 层面）
- 优化策略（How 层面）
- 非学术写作

## 必收集的最小输入集

| 编号 | 字段 | 例 |
|------|------|-----|
| ① | 研究对象 | "B公司" / "新能源汽车行业" |
| ② | 主题 | "生产管理" / "数字化转型" / "营销渠道" |
| ③ | 关键事实 | 用户已有的数据/事实/调研结论 |
| ④ | 是否匿名 | "是" → 走匿名化映射；"否" → 保留真实名称 |
| ⑤ | 论文类型 | 学术硕士/博士/MBA/期刊 |

## 快速使用

### 1. 在模型中加载 skill

让模型读取 `SKILL.md` 即可。模型会自动：
- 询问 5 项必填信息
- 套用三种结构模板（企业案例 / 行业政策 / 技术系统）
- 执行学术规范、匿名化、去 AI 痕迹
- 产出正文 + 质量自检报告 + 待补充清单

### 2. Markdown → Word

```bash
./scripts/gen_docx.sh input.md output.docx
```

如需使用学校/期刊自定义模板：
```bash
REFERENCE_DOC=/path/to/your/template.docx ./scripts/gen_docx.sh input.md output.docx
```

### 3. 看完整示例

打开 `examples/C公司生产管理现状.md` 看一份真实产出（6800 字），配合 `examples/质量自检报告.md` 看 6 大项自检结果。

## 核心设计

### 三种结构模板

1. **企业案例型**（最常用）— 3.1 公司概况 / 3.2 流程现状 / 3.3 数字化现状
2. **行业政策型** — 行业概况 / 市场规模 / 竞争格局 / 政策环境
3. **技术系统型** — 概念界定 / 国内外研究 / 主流技术路线 / 典型应用

### 4 项硬规则（每次写作必查）

1. **数据真实性** — 不编造、未披露就标注、必带截止时间
2. **匿名化映射** — 13 类敏感信息的标准化替换规则
3. **学术规范** — 第三人称、来源词齐、首行缩进、过渡句
4. **去 AI 痕迹** — 24 条 humanizer 规则自查

## 与其他 skill 的边界

- `thesis-assistant` — 通用论文导师/评审；本 skill 是专门写"现状"章节的子模块
- `humanizer` — 通用去 AI 痕迹；本 skill 内置 humanizer 规则自查
- `academic-research-expert` — 文献检索；现状章节偶尔需要查行业数据
- `minimax-docx` — Word 转换（更强大的 OpenXML 方案）；本 skill 的 gen_docx.sh 是 pandoc 简化版

## 常见问题

**Q1：用户没给关键事实怎么办？**
A：退回 Step 1 补全；如果用户坚持要写，按"未披露"标注，不编造。

**Q2：论文不在覆盖范围怎么办？**
A：按 §3 通用模板灵活处理，仍产出可用的初稿；如需更细致辅导，转 `thesis-assistant`。

**Q3：用户要求保留真实公司名怎么办？**
A：把匿名化映射表跳过即可，正文保留真实公司名、股票代码、注册地等。

**Q4：现状章节要不要带"问题分析"？**
A：本 skill 严格只做"现状事实描述"。问题分析单独成第 4 章，避免越界。如需衔接，章节末尾留 1 句过渡句即可。

**Q5：怎么检查去 AI 痕迹效果？**
A：参考 `references/anti-patterns.md` 的 10 类反模式逐项排查；如仍有"AI 味"，调用 `humanizer` skill 做二次精修。
