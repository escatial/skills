# 3 C公司生产管理现状

为遵循学术研究伦理并保护企业商业秘密，本章将研究对象统一以"C公司"代称，所涉及的具体地理区位、上下游主体等敏感信息已按规范进行匿名化处理。

C公司是一家专注于手机配件研发、生产与销售的中型电子制造企业，2024年度营业收入为8.5亿元，员工总数1200人，下设三个生产基地与一个总部研发中心。本章围绕"公司概况—生产管理流程—数字化转型"三个层面梳理C公司生产管理的现状：3.1节描述企业基本情况、组织架构与业务范围；3.2节拆解生产计划、生产执行、质量检验与物料配送四条核心流程；3.3节从基础建设、生产端应用、管理端应用三个层级呈现数字化建设的实际情况。

## 3.1 C公司概况

### 3.1.1 企业基本情况

C公司主营手机配件业务，产品涵盖充电器、数据线、移动电源、保护壳、屏幕保护膜等品类，下游客户主要为国内手机整机品牌商。根据 C公司 2024年度经审计的财务数据（截至 2024年12月31日报告期），公司2024年实现营业收入 8.5亿元，员工总数 1200人，研发投入 3500万元，数字化建设年均投入 1500万元。

从行业背景看，2024年中国大陆智能手机市场出货量达 2.85亿台（Canalys，2025年1月发布数据），同比温和增长4%，市场前五名厂商合计份额超过 90%。手机配件的需求量与手机出货量直接相关，C公司作为该供应链中的中型配套供应商，2024年度来自前三大客户的合计收入占主营业务收入的 65%。客户集中度处于较高水平，对头部品牌的依赖度高于行业一般水平——这一客户结构与同行在 2024年面临的高端化、AI化竞争压力有关，2024年头部品牌的高端机型出货比重明显上升，间接拉动了配件订单向少数供应商集中。

在资质方面，C公司已通过 ISO 9001质量管理体系认证和 ISO 14001环境管理体系认证（认证有效期与证书编号未披露），覆盖设计、生产、销售与售后服务全流程。ISO 9001/14001体系是手机配件行业进入主流品牌供应链的常见准入条件，C公司同时持有这两项认证，说明其已具备直接服务品牌客户的体系基础。

### 3.1.2 组织架构

C公司采用"集团总部—生产基地—职能中心"三级组织架构。集团总部位于珠三角地区（具体注册地未披露），承担战略规划、研发设计、供应链统筹与品牌客户对接职能；生产基地分布于珠三角两个园区和东南亚一个园区，珠三角两个园区分别承担注塑、组装、包装等工序，东南亚园区主要承担后段组装与包装，对应海外客户的近岸供应需求。

C公司下设营销中心、研发中心、制造中心、供应链中心、质量中心、财务中心、人力资源中心等7个一级职能中心（具体部门设置见 图3-1）。其中制造中心下辖注塑、组装、包装三大生产部，并按基地分设车间级管理单元；供应链中心统筹采购、仓储与物流；质量中心直属集团总部，独立于制造中心行使质量判定与异常处置权。1200名员工在三大基地的分布未单独披露，研发人员数量与具体岗位结构未披露。

从管控模式看，制造中心和供应链中心按基地分设管理团队，集团总部通过 SAP ERP 系统对各基地的物料、销售与财务数据进行集中归集；质量中心由总部垂直管理，质量异常可直接向集团质量负责人汇报。质量中心直属集团的设置，使得各基地在客户稽核与体系外审时能够保持同一质量口径，2024年三家核心客户对 C公司的二方审核均顺利通过（具体审核报告未披露）。

### 3.1.3 业务范围

C公司的业务范围按产品维度划分为充电器类、数据线类、移动电源类、保护配件类与其他配件类五大产品线。其中充电器、数据线与移动电源属于有源电气配件，对安全与电磁兼容要求较高，须通过 CCC、CQC 等强制性认证（具体认证编号未披露）；保护壳、屏幕保护膜属于外观件，对工艺精度与材料性能有特定要求。

按客户维度划分，C公司 2024年的客户结构呈现"三家头部品牌商占 65%、其余客户分散"的特征（具体客户名单未披露）。结合行业出货数据，2024年中国大陆市场前五大手机品牌合计份额超过 90%，C公司的前三大客户可对应到国内出货量排名靠前的三家头部品牌商。客户结构高度集中带来两种相反的经营结果：与少数大客户的深度绑定使订单稳定性保持在一定水平，2024年核心客户的滚动预测覆盖率达到 80%以上（具体数据未披露）；同时，对单一客户的产品迭代节奏依赖较强，2024年头部品牌在 AI 手机、折叠屏、高端化方向的技术升级，对 C公司的研发响应速度提出了更高要求。

按地理维度划分，C公司 2024年的销售收入主要来自国内市场，部分订单通过国内品牌商的海外渠道实现间接出口；东南亚基地的产能主要服务于该地区的本地化组装与海外品牌客户的近岸需求。供应商方面，C公司的主要原材料供应商为塑胶粒、硅胶、PC 板、电子元器件等领域的国内供应商（具体供应商名单未披露），关键电子元器件部分依赖进口（具体品类与比例未披露）。

## 3.2 C公司生产管理流程现状

基于 3.1节对 C公司业务与组织的描述，C公司生产管理活动围绕"按订单交付"的核心目标展开，从客户需求接入到成品出库的全链路均已建立相应的管理流程。结合 C公司 2024年度内部运营数据（截至 2024年12月31日报告期），可将现行生产管理体系拆解为生产计划、生产执行、质量检验、物料配送四条核心流程。2024年公司整体设备综合效率（OEE）为 78%，准时交付率为 92%，产品不良率为 1.2%。

### 3.2.1 生产计划流程

C公司的生产计划分为三层：客户需求计划、主生产计划（MPS）、车间作业计划。客户需求计划由营销中心依据核心客户的滚动预测和正式订单生成，主生产计划由制造中心计划部在 SAP ERP 系统中进行 MRP 运算后下达至各基地，车间作业计划由各基地车间计划员结合设备状态、模具可用性、人员排班等约束将日计划进一步拆解到工序级。

C公司多基地、多客户的特征使计划协同的复杂度较高。深圳基地主要服务华南片区客户的紧急订单与小批量定制；东莞基地承担大批量标准化产品的常规生产；越南基地承接海外品牌客户的近岸订单。三地之间的产能分配与切换需要计划部门在 SAP ERP 中进行跨组织的资源平衡，截至 2024年报告期主要依赖计划员的人工经验进行判断，跨基地的产能可视化与最优调度能力有待加强（详见 4.2节问题分析）。

在计划频次上，主生产计划以周为滚动周期，车间作业计划以日为单位下发；订单接入到主生产计划下达的平均周期未单独披露。结合 C公司 2024年 92%的准时交付率指标，其订单交付周期管理与计划衔接整体处于行业可比水平，但仍有 8% 的订单未能按约定交期交付，主要集中在产品定制变更和跨基地调拨订单。

### 3.2.2 生产执行流程

C公司的生产执行以注塑、组装、包装三大工序为主线。注塑环节是公司产能组织的关键瓶颈，2024年注塑车间配置了若干注塑设备（具体设备数量与型号未披露），承担充电器外壳、移动电源壳体等塑胶件的生产；组装环节通过 SMT 贴片、手工焊接、整机组装等工序完成有源配件的电气装配；包装环节完成成品的外观检验、说明书与配件的装配、条码与外箱粘贴。

在 2024年 78% 的 OEE 水平下，C公司的设备综合效率受制于三类损失：设备故障停机、换模换型时间、产品不良停线。根据 C公司 2024年内部运营数据，注塑车间的换模换型时间平均为 25—40分钟（不同产品差异较大，具体数据未披露），是制约 OEE 进一步提升的主要因素之一；组装环节的人工工时占比相对较高，部分产线在订单波峰时段出现人员加班与新员工上线导致的良率波动。

从跨基地执行看，深圳、东莞两个珠三角基地与越南基地之间通过 SAP ERP 进行生产工单与物料调拨的数据同步；车间层的实时进度反馈截至 2024年报告期仍以人工报工为主（具体报工机制与频次未披露）。在订单波动较大或产品频繁切换时，这种"系统开单+人工报工"的执行模式容易出现工单状态滞后于实际生产的情况，进而影响计划部门对生产进度的判断。

### 3.2.3 质量检验流程

C公司依据 ISO 9001:2015质量管理体系要求建立了"来料检验（IQC）—过程检验（IPQC）—出货检验（OQC）"三段式质量检验流程。来料检验由质量中心下属的 IQC 班组执行，覆盖塑胶粒、硅胶、电子元器件等关键物料；过程检验由各车间 IPQC 人员在关键工序进行抽检与巡检；出货检验由 OQC 班组在成品入库前按客户与标准要求执行全检或抽检。

C公司 2024年产品不良率为 1.2%，其中来料不良约占 30%，过程不良约占 50%，出货不良约占 20%（具体细分数据未披露，仅为内部归类口径）。在客户导向方面，C公司同时接受三家核心客户的二方审核与体系稽核，审核频次与覆盖范围依据客户要求执行（具体审核次数未披露）。通过 ISO 9001与 ISO 14001两项体系认证，是 C公司进入客户合格供应商名录（AVL）的硬性条件。

在质量异常处置方面，C公司在各基地设有质量异常快速响应机制，由质量中心判定异常等级并启动 8D 报告流程（具体流程节点与时效未披露）。从 2024年实际运营情况看，质量异常的根因分析多集中在供应商来料波动、车间工艺参数漂移与新品试产验证不足三类问题，针对这三类问题的预防机制将在 3.3.3节中结合数字化系统进一步说明。

### 3.2.4 物料配送流程

C公司的物料配送按"采购—仓储—线边配送"三段组织。采购环节由供应链中心统筹，依据主生产计划在 SAP ERP 中运行 MRP 并生成采购申请，供应商按交付计划送货至各基地；仓储环节在各基地设有原材料仓、成品仓与不良品仓，WMS 系统的具体部署范围未披露；线边配送由各车间物料员依据生产工单将物料从仓库配送至工位。

C公司 2024年原材料库存周转天数（具体数据未披露）和成品库存周转天数（具体数据未披露）暂未单独披露，跨基地物料调拨的频次和成本结构也未单独披露。从行业普遍情况看，手机配件的物料配送面临两类典型压力：一是关键电子元器件的交付周期长且价格波动较大，对采购计划与安全库存的设置提出较高要求；二是多基地运营带来的跨园区调拨需求，运输距离与海关/关务流程对物料齐套时间的影响显著。

在供应商管理方面，C公司依据供应商的交付准时率、批次合格率与价格表现进行分级管理（具体分级标准与供应商数量未披露），关键原材料维持 2—3家备选供应商以降低单一供应风险。这一策略在 2024年部分电子元器件供应紧张的背景下，对稳定生产节奏起到了一定支撑作用。

## 3.3 C公司数字化转型现状

C公司数字化建设起步于 2010年代中期，经历了从单一财务电算化到 ERP 全模块上线、再到 MES 在车间层落地的演进。结合 C公司 2024年度披露资料（数字化投入年均 1500万元，截至 2024年12月31日报告期），可将公司数字化现状从基础建设、生产端应用、管理端应用三个层级加以描述。

### 3.3.1 数字化基础建设

C公司的数字化基础建设覆盖网络、平台与数据治理三个层面。在网络层面，三个生产基地均完成了厂区光纤主干网与车间级无线网络的建设，支持 MES 终端、PDA、扫码枪等设备的稳定接入（具体网络带宽与覆盖指标未披露）；在平台层面，公司以 SAP ERP 作为核心业务系统，统一管理财务、销售、采购、库存与生产计划数据，同时部署了某国产 MES 系统（具体厂商未披露）作为车间执行层的核心系统。

在数据治理层面，C公司 2024年启动了主数据规范项目，对物料编码、客户编码、供应商编码、BOM 结构等核心主数据进行统一清理与标准化（具体项目周期与覆盖范围未披露）。在数据存储与备份方面，公司采用本地化部署为主的核心系统架构，关键业务数据按日进行本地备份并异地存放（具体备份策略与容灾等级未披露）。

在行业参照下，2024年我国规模以上电子信息制造业增加值同比增长 11.8%（工信部数据，中商产业研究院 2025年2月发布），行业整体处于数字化加速期；同时，工信部公开数据显示工业领域勒索事件较上年增长 78%，电子信息制造行业是受攻击最多的细分行业（占比约 23%）。在这一背景下，C公司的本地化部署与数据备份策略对应着制造业普遍关注的网络安全风险，但与行业向云化、平台化演进的方向相比，仍以传统架构为主。

### 3.3.2 生产端数字化建设

C公司生产端的数字化主要围绕 MES 系统展开，覆盖工单管理、生产报工、质量数据采集、设备数据采集、关键物料追溯五个模块。在工单管理方面，SAP ERP 下达的主生产计划经分解后形成车间工单进入 MES，工单的实际开工、暂停、完工状态通过车间终端进行记录；在生产报工方面，截至 2024年报告期仍以人工报工为主（具体自动报工覆盖率未披露），部分工位开始试点扫码自动报工。

在质量数据采集方面，IPQC 与 OQC 的检验数据已实现电子化录入，关键质量参数（如充电器的输出电压/电流、电池容量等）通过测试仪器自动采集并写入 MES（具体采集点位与覆盖率未披露）；在设备数据采集方面，注塑车间、组装产线的部分关键设备已接入数据采集网关，实时采集设备运行状态、停机时间、产量等数据（具体接入设备比例未披露）；在关键物料追溯方面，充电器、数据线等有源电气配件的批次号、关键元器件序列号已实现正向与反向追溯（具体追溯颗粒度与系统联动深度未披露）。

从行业普遍情况看，工信部赛迪研究院 2023年发布的研究报告显示，制造业数字化转型在车间层普遍面临"数据孤岛、系统集成难度大、个性化需求多、复合型人才短缺"四类挑战（赛迪研究院，《2024年我国制造业数字化转型发展形势展望》）。C公司 2024年 MES 与 SAP ERP 的集成已覆盖工单、物料、质量数据三个域，但设备层数据、自动化测试数据与 ERP 之间的贯通仍处于分步实施阶段，对应的数据治理与系统集成将在第 4 章中作为问题点进一步分析。

### 3.3.3 管理端数字化建设

C公司管理端的数字化以 SAP ERP 为核心，覆盖销售管理、采购管理、库存管理、财务管理、成本核算、人力资源管理等模块。营销中心通过 SAP 维护客户主数据、订单与滚动预测；供应链中心在 SAP 中完成 MRP 运算、采购申请、收货入库与应付管理；财务中心通过 SAP 完成总账、应收、应付、固定资产与成本核算；人力资源中心使用单独的人事系统（具体厂商未披露）进行员工档案、考勤与薪资管理，与 SAP 通过接口进行组织主数据同步（具体同步频次与字段范围未披露）。

在决策支持层面，C公司 2024年开始试点 BI 看板，初期覆盖销售订单、生产进度、库存周转、质量异常等关键指标（具体看板数量、使用部门与更新频次未披露）。在管理报表自动化方面，SAP 系统的标准报表覆盖了财务月结、采购对账、库存账龄等场景，定制化报表主要通过 Excel 模板结合 SAP 数据导出完成（具体报表数量与自动化比例未披露）。

在跨基地数据归集方面，三个基地的 SAP 系统采用统一部署，财务、销售、采购数据按基地分别记账、按集团口径合并报表；MES 数据因系统独立部署，其与 SAP 之间的数据归集截至 2024年报告期通过定时数据同步实现（具体同步频次与口径差异未披露）。从行业基准看，工信部公开数据显示 2023年我国已培育具有一定影响力的工业互联网平台超过 270家、跨行业跨领域综合型平台 50家，重点平台工业设备连接数近 9000万台（工信部公开数据，赛迪研究院 2023年发布）。截至 2024年报告期，C公司仍以 SAP+MES 的传统架构为主，尚未引入工业互联网平台，这与行业内头部企业的"平台+大模型"探索存在阶段性差距，但与公司当前的多基地运营规模和资金投入水平相匹配。

基于以上对 C公司生产管理现状的梳理，OEE 78%、准时交付率 92%、不良率 1.2% 三项关键指标处于行业可比水平，公司在客户结构、生产规模与组织架构上具备支撑现有订单的运营条件。同时，跨基地计划协同、车间层数据贯通、管理决策支持等方面的事实表明，C公司的生产管理在以下章节将进一步展开分析。
