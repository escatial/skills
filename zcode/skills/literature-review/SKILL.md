# 文献综述自动撰写技能

为硕士论文题目自动生成高质量、符合学术规范的文献综述，并输出为 Word 文档。本技能覆盖**文献检索 → 筛选 → 批判性写作 → 引用插入 → Word 原生脚注生成**的完整流程。

## 触发条件

- 用户提供硕士论文题目并要求撰写文献综述
- 用户提及：文献综述、国内外研究现状、研究综述、相关研究梳理、literature review
- 需要按 GB/T 7714-2015 标准输出引用

## 核心约束（不可妥协）

| 维度 | 要求 |
|------|------|
| 总文献数 | ≥ 70 篇 |
| 英文文献 | ≥ 24 篇（≥ 总数 1/3） |
| 时间范围 | 仅限 2023-2026 年 |
| 文献类型 | 仅限期刊论文[J]，排除硕博[D]、专著[M]、新闻、博客 |
| 综述字数 | ≥ 8000 汉字 |
| 来源验证 | 必须在 Google Scholar / CNKI 可查，禁止虚构 |
| 引用形式 | 正文"作者（年份）"夹注 + Word 原生脚注 |
| 脚注实现 | 必须使用 OpenXML `<w:footnoteReference>`，禁止手动输入上标数字 |

---

## 核心工作流程（8 步）

每步完成后进入下一步，禁止跳步：

1. **解析需求** — 明确题目、组织方式、研究边界
2. **检索文献** — 英文（Scholar）+ 中文（CNKI/万方），构建 70+ 篇文献池
3. **筛选与分组** — 按指定组织方式（国内国外 / 主题）分类
4. **撰写综述** — 批判性写作，"作者（年份）"夹注形式
5. **插入引用** — Word 原生脚注，GB/T 7714-2015 格式
6. **质量检查** — 验证数量、比例、年份、格式、来源
7. **最终核查** — 交叉验证引用与脚注对应，验证 OpenXML 真实性
8. **生成 Word** — C# + OpenXML SDK 输出，确保真实 `<w:footnoteReference>`

## Step 3：文献筛选与分组

2. **年份**：2023-2026 年
3. **质量**：权威期刊，非水刊
4. **可验证**：Google Scholar 或 CNKI 可检索到完整元数据

```
  ├─ 子主题 1
  ├─ 子主题 2

国内外研究对比与评述
```

#### 选项 B：按研究主题/流派划分

```

主题 2：XXXX
主题 3：XXXX
主题间联系与冲突分析
```

## Step 4：综述撰写

### 正文引用表述规范（强制执行）

| 形式 | 示例 |
|------|------|
| 中文单作者 | 李明华（2024）认为供应链数字化转型能显著提升运营效率 |
| 英文单作者 | Smith（2024）通过实证研究发现组织敏捷性对绩效具有正向影响 |
| 中文两位 | 张三和李四（2023） |
| 英文两位 | Smith and Jones（2024） |
| 中文三位及以上 | 王五等（2024） |
| 英文三位及以上 | Smith et al.（2023） |
| 同一作者多年 | 张三（2022，2023）、Smith（2023, 2024） |

**作者姓名规范**：
- 英文：只写姓氏，如 `Johnson（2023）` 而非 `A. B. Johnson（2023）`
- 中文：写全名，如 `李明华（2024）`

### 脚注位置（强制）

> 脚注编号置于「该学者观点最后一个字之后，句中标点之前」

✅ **正确**：
- 李明华（2024）认为供应链数字化转型能显著提升运营效率¹，但在 XXX 方面仍存在不足。
- Smith（2023）发现数字化转型与企业绩效之间存在显著正相关²。然而，这一关系受到...

❌ **错误**：
- 李明华（2024）¹认为...（脚注在观点动词前）
- 李明华（2024）认为...效率，¹但...（脚注在标点后）

❌ **禁止**：仅用数字上标 [1] 替代"作者（年份）"夹注

### 批判性写作原则

**禁止**：`A 认为... B 认为... C 认为...` 的简单罗列

**必须**包含：
- 比较与对比
- 评价优缺点
- 识别共识与争议

**示范句式**：
> 虽然张三（2022）和李四（2023）都认同 XXXX，但在 XXX 方向上存在根本分歧。张三（2022）采用实验方法发现...，而李四（2023）通过案例分析指出...，二者的差异可能源于...

### 问题导向（综述末尾）

必须明确指出 **Research Gap**：

> 综上所述，尽管已有丰富成果，但针对...情境下的...问题尚无人探究。本研究将基于...视角，致力于...

### 结构模板（≥ 8000 汉字）

```
2 文献综述（或"国内外研究现状" / "相关研究综述"）

2.1 引言段
    — 明确综述范围、目标和组织结构

2.2 [第一个核心主题/流派]
    — 关键概念、主要发现、内部争论

2.3 [第二个核心主题/流派]
    — ...

2.4 主题间的联系与冲突（或"国内外研究对比"）
    — 不同流派间的对立、互补或演进关系

2.5 研究方法评述
    — 常用方法的优势和局限

2.6 研究空白与本研究定位
    — 总结不足 → 引出研究问题 → 简要说明应对策略
```

详见 `references/review-writing-guide.md`。

## Step 5：引用插入

### 核心原则：使用 Word 原生引用功能

> 正文采用「作者（年份）夹注 + Word 原生脚注/交叉引用」，必须通过 OpenXML 的 `<w:footnoteReference>` 或 `<w:crossReference>` 元素实现，**绝对禁止**手动输入上标数字。

### 方式一：Word 脚注（默认推荐）

**OpenXML 技术本质**：Word 脚注不是手动输入的上标数字，而是通过 OpenXML 中的 `<w:footnoteReference>` 元素与文档的 `FootnotesPart` 建立链接。Word 自动管理编号，增删脚注时编号自动更新。

**正文中插入**：
```xml
<w:footnoteReference w:id="N"/>
```

**脚注内容定义**（在 `footnotes.xml` 中）：
```xml
<w:footnote w:id="N">
  <w:p>
    <w:pPr><w:pStyle w:val="FootnoteText"/></w:pPr>
    <w:r><w:footnoteRef/></w:r>
    <w:r><w:t> 张三, 李四. 数字化转型对企业绩效的影响研究[J]. 管理世界, 2024, 40(3): 120-135.</w:t></w:r>
  </w:p>
</w:footnote>
```

### 方式二：Word 交叉引用

适用场景：需要在正文多次引用同一脚注，或建立对同一文献引用的链接。

通过 `<w:bookmarkStart>` / `<w:bookmarkEnd>` + `<w:crossReference>` 或 `<w:hyperlink>` 实现动态链接。

### 脚注内容格式（GB/T 7714-2015）

**中文期刊论文**：
```
作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**英文期刊论文**：
```
Author. Title[J]. Journal Name, Year, Vol(No): Pages.
```

详见 `references/gbt7714-guide.md` 和 `references/footnotes-openxml-reference.md`。

## Step 7：最终核查（文档输出前强制执行）

### 7.1 正文引用与文献池交叉验证
- 逐段扫描正文，提取所有"作者（年份）"夹注
- 验证每个夹注与文献池完全匹配
- 统计引用总数，确保 ≤ 文献池范围

### 7.2 夹注与脚注对应关系验证
- 每个夹注后必须紧跟脚注编号
- 编号连续、无遗漏、无重复
- 核对脚注中的作者、年份与正文夹注完全一致
- 验证脚注位置：观点最后一字后、标点前

### 7.3 Word 引用功能真实性验证（关键）

> 此步骤确保生成的是真实 Word 脚注，而非手动编号。

- [ ] 验证 OpenXML 结构：包含 `word/footnotes.xml` 部分
- [ ] 验证脚注引用元素：包含 `<w:footnoteReference>` 而非普通 `<w:t>` 文本
- [ ] 验证 ID 关联：每个 `<w:footnoteReference w:id="N"/>` 在 `footnotes.xml` 中存在对应 `<w:footnote w:id="N">`
- [ ] 验证编号自动生成：OpenXML 中不硬编码上标数字
- [ ] 在 Word 中打开，测试增删脚注后其他编号自动更新

**检测手动编号的标志**：
- 正文编号是普通 `<w:t>` 文本而非 `<w:footnoteReference>` 元素
- 删除一个脚注后其他编号不自动更新
- `footnotes.xml` 中不存在与正文引用对应的脚注定义

### 7.4 文献信息准确性最终确认
- 重新抽查至少 30% 文献，二次确认元数据
- 重点核查作者姓名、标题、期刊、年卷期页码

### 7.5 核查结果处理
- 全部通过 → 进入 Step 8
- 发现问题 → 修正后重新执行 Step 7

## Step 8：Word 文档生成

### 8.1 核心技术要求（强制）

**必须使用 `<w:footnoteReference>` 元素**：

```csharp
// ✅ 正确：创建真实的 Word 脚注引用
Run footnoteRefRun = new Run(
    new FootnoteReference { Id = footnoteId }
);

// ❌ 错误：禁止使用手动上标文本模拟脚注
// Run fakeFootnote = new Run(
//     new Text("1") { Space = SpaceProcessingMode.Preserve }
// );
// fakeFootnote.RunProperties = new RunProperties(
//     new VerticalTextAlignment { Val = VerticalPositionValues.Superscript }
// );
```

**完整 OpenXML 脚注结构**：

```csharp
// 1. 创建 FootnotesPart
FootnotesPart footnotesPart = mainDocumentPart.AddNewPart<FootnotesPart>();

// 2. 定义脚注内容
Footnote footnote = new Footnote(
    new Paragraph(
        new ParagraphProperties(new ParagraphStyleId { Val = "FootnoteText" }),
        new Run(new FootnoteReferenceMark()),  // Word 自动生成的脚注编号
        new Run(new Text(" 张三, 李四. 数字化转型对企业绩效的影响研究[J]. 管理世界, 2024, 40(3): 120-135."))
    )
) { Id = footnoteId };

// 3. 将脚注添加到 FootnotesPart
footnotesPart.Footnotes = new Footnotes(footnote);

// 4. 在正文中插入脚注引用
Run refRun = new Run(new FootnoteReference { Id = footnoteId });
```

### 8.2 排版规范

| 元素 | 字体 | 字号 | pt |
|------|------|------|-----|
| 标题 | 黑体 | 小二号 | 18pt |
| 一级标题 | 黑体 | 三号 | 16pt |
| 二级标题 | 黑体 | 小三号 | 15pt |
| 三级标题 | 黑体 | 四号 | 14pt |
| 正文 | 宋体 / Times New Roman | 小四号 | 12pt，1.5 倍行距 |
| 脚注 | 宋体 / Times New Roman | 六号 | 7.5pt |

- 脚注位置：页面底部，自动编号
- 页码：底部居中
- 生成后清理中间产物，只输出最终 docx

### 8.3 验证输出文件

- [ ] 用压缩工具打开 docx，检查 `word/footnotes.xml` 存在
- [ ] 检查 `footnotes.xml` 包含与引用数量相等的 `<w:footnote>` 元素
- [ ] 检查正文 `document.xml` 包含 `<w:footnoteReference>` 元素
- [ ] 在 Word 中打开，确认脚注编号是上标格式且位于页面底部
- [ ] 删除一个脚注，验证其余脚注编号自动更新（**关键测试**）

**调用方式**：`./scripts/docx build`（参照 docx 技能的完整流程）

## 风险防控

### 文献来源准确性（最高优先级）

1. 每篇文献必须通过 scholar 数据源验证
2. **禁止虚构**任何文献信息（作者、题名、刊名、年份、卷期页码）
3. 禁止引用无法验证的文献
4. 撰写过程中实时监控中英文比例
5. "作者（年份）"夹注必须与脚注严格一一对应
6. 必须使用 Word 原生脚注，禁止手动输入编号

### 学术不端防范

- 所有引用文献必须真实存在
- 引用内容必须与原文意思一致，不得歪曲
- 脚注信息必须完整准确，便于读者溯源
- "作者（年份）"表述必须与实际文献完全匹配，禁止张冠李戴
- Word 脚注必须是功能性链接，不得是装饰性手动编号
