# 文献综述写作指南

本指南提供硕士论文文献综述的批判性写作模板与技巧。

## 一、综述的核心目标

文献综述不是文献的简单堆砌，而是要回答：

1. **现有研究关注了什么？**（what）
2. **现有研究怎么做的？**（how）
3. **现有研究的结论是什么？**（finding）
4. **现有研究的不足是什么？**（gap）

> 综述的最终目的是论证 **"为什么需要本研究"**。

---

## 二、写作原则

### 2.1 三大铁律

| 铁律 | 说明 |
|------|------|
| 批判性 | 不简单罗列，必须比较、评价、识别争议 |
| 逻辑性 | 按主题/时间/方法组织，而非按作者 |
| 前沿性 | 突出近三年研究进展，凸显时效性 |

### 2.2 禁止的写作模式

❌ **罗列式**：
```
A 认为... B 认为... C 认为...
```

❌ **流水账**：
```
张三（2022）研究了...。李四（2023）研究了...。王五（2024）研究了...
```

❌ **无主线**：
```
本节将介绍 XX 领域的研究现状。
（然后无层次罗列）
```

### 2.3 推荐的写作模式

✅ **比较式**：
```
虽然张三（2022）和李四（2023）都认同 XXXX，但在 XXX 方向上存在根本分歧。
张三（2022）采用实验方法发现...，而李四（2023）通过案例分析指出...，
二者的差异可能源于...
```

✅ **演进式**：
```
该领域研究经历了三个阶段：早期（2023-2024）关注...，近期（2025）转向...，
最新研究（2026）开始探索...。
```

✅ **问题导向式**：
```
尽管现有研究丰富，但仍存在以下不足：第一，...；第二，...；第三，...。
本研究将针对这些问题，从...视角展开研究。
```

## 三、结构模板详解

### 3.1 完整章节结构

```
2 文献综述

2.1 引言段（300-500 字）
2.2 核心主题 1（约 2000 字）
2.3 核心主题 2（约 2000 字）
2.4 核心主题 3（约 2000 字，可选 2-4 个主题）
2.5 主题间联系与冲突（约 800 字）
2.6 研究方法评述（约 500 字）
2.7 研究空白与本研究定位（约 500 字）
```

**总字数**：≥ 8000 汉字

### 3.2 各部分写作要点

#### 2.1 引言段

**核心任务**：
- 交代综述范围（研究主题、时间跨度、文献类型）
- 说明综述组织结构
- 点出综述的核心问题

**示范**：
```
本部分对 XXX 领域的国内外研究现状进行系统综述。文献检索范围限定于
2023-2026 年发表的高质量期刊论文，文献来源包括 Google Scholar 和 CNKI。
本部分共纳入文献 70 篇，其中英文文献 24 篇，中文文献 46 篇。
综述组织如下：首先回顾 XXX 的概念内涵与理论基础；其次梳理 XXX 的
影响因素与作用机制；再次评述 XXX 的研究方法；最后总结现有研究的
不足，并提出本研究的切入点。
```

#### 2.2-2.4 主题分节

**每节内部结构**：
```
[节标题]

(1) 关键概念界定
    — 该主题涉及的核心概念
    — 概念演进与分歧

(2) 主要研究发现
    — 按子主题/方法/视角分组论述
    — 每组至少 2-3 篇文献支撑
    — 必须包含比较与评价

(3) 内部争论
    — 不同观点的对立
    — 争论的根源（方法/样本/视角）
    — 当前共识
```

#### 2.5 主题间联系与冲突

**写作要点**：
- 找出主题间的逻辑递进或互补关系
- 明确指出主题间的对立或冲突
- 分析冲突背后的方法论根源

**示范句式**：
```
值得注意的是，主题 1 与主题 2 之间存在显著的理论张力。
一方面，主题 1 的研究者强调...，而另一方面，主题 2 的研究指出...
这种分歧可能源于二者采用了不同的分析视角——前者侧重宏观层面，
后者聚焦微观机制。
```

#### 2.6 研究方法评述

**写作要点**：
- 归纳本领域常用的研究方法（如问卷调查、案例分析、计量模型、仿真实验）
- 评价各方法的优势与局限
- 指出方法论的演进趋势

**示范**：
```
从研究方法来看，现有研究主要采用以下几类方法：第一，问卷调查法，
如张三（2024）¹和李四（2023）²，该方法便于大样本检验，但易受共同方法偏差影响；
第二，案例分析法，如王五等（2024）³，能够深入剖析机制，但外部效度受限；
第三，计量经济模型，如赵六（2025）⁴，内生性问题处理是关键。整体而言，
近年来研究方法呈现"混合化"趋势，定性定量结合的研究逐渐增多。
```

#### 2.7 研究空白与本研究定位

**写作要点（强制）**：
- 总结现有研究的具体不足
- 引出本研究的核心问题
- 简要说明应对策略

**示范**：
```
综上所述，现有研究在以下方面仍存在不足：第一，研究情境上，
多聚焦于西方成熟市场，对新兴市场情境下的...探讨不足；第二，
研究方法上，现有成果以截面分析为主，对...动态演变关注有限；
第三，研究视角上，鲜有学者从...角度审视...问题。本研究将基于
...视角，采用...方法，致力于回答...问题，以期弥补上述研究空白。
```

## 四、批判性写作技巧

### 4.1 五种对比维度

| 维度 | 提问 |
|------|------|
| 方法对比 | 不同研究用了什么方法？差异在哪？ |
| 样本对比 | 样本规模、行业、地域有何不同？ |
| 结论对比 | 不同研究的结论是否一致？分歧在哪？ |
| 视角对比 | 理论视角有何差异？哪个更具解释力？ |
| 时效对比 | 早期与近期研究有何演变？ |

### 4.2 评价性词汇

**正面评价**：
- 提供了新的理论视角
- 弥补了 XX 研究的不足
- 实证设计严谨
- 结论具有普适性

**批评性评价**：
- 样本局限于...
- 内生性问题未充分处理
- 缺乏跨文化比较
- 结论的可推广性受限
- 对...因素的考虑不足

**中性评价**：
- 与...研究的结论一致
- 与...研究的发现存在分歧
- 进一步证实/挑战了...

### 4.3 过渡句模板

**主题过渡**：
```
基于上述分析，可以发现...。然而，现有研究对...的关注相对有限，
下文将围绕...展开综述。
```

**对比过渡**：
```
与之形成鲜明对比的是，...
```

**递进过渡**：
```
在...的基础上，学者们进一步将研究拓展到...
```

## 五、文献池构建策略

### 5.1 检索-筛选-补充循环

```
初始检索 → 筛选 70+ 篇 → 分类分组 → 发现空白 → 针对性补充检索
   ↑                                              ↓
   └──────────────── 重复直至满足要求 ←───────────┘
```

### 5.2 中英文文献平衡策略

| 阶段 | 策略 |
|------|------|
| 初始检索 | 英文优先，覆盖主流理论视角 |
| 中期检索 | 中文跟进，补充本土情境研究 |
| 后期调整 | 检查比例，确保英文 ≥ 1/3 |

### 5.3 文献池记录表

维护一个 `literature_pool.md`：

| 编号 | 作者 | 年份 | 题名 | 期刊 | 卷期 | 页码 | 语言 | 主题分类 |

| 1 | Smith J A | 2024 | Digital Transformation... | J. Operations Management | 45(3) | 230-251 | EN | 主题1 |
| 2 | 李明华 | 2024 | 数字化转型研究... | 管理世界 | 40(3) | 120-135 | CN | 主题1 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... |

## 六、字数控制技巧

### 6.1 字数分配建议

| 部分 | 字数 | 占比 |
|------|------|------|
| 引言段 | 400 | 5% |
| 主题 1 | 2000 | 25% |
| 主题 2 | 2000 | 25% |
| 主题 3 | 1500 | 19% |
| 主题间联系 | 800 | 10% |
| 方法评述 | 600 | 8% |
| 研究空白 | 700 | 8% |
| **合计** | **8000** | **100%** |

### 6.2 充实篇幅的方法

- **深化比较**：每个主题至少 2-3 处跨研究比较
- **方法论评述**：单独评价各方法优劣
- **背景铺垫**：交代研究演进的历史脉络
- **影响分析**：分析研究结论的实践/理论意义

## 七、常见错误清单

- [ ] 引言段过于简短（< 200 字）
- [ ] 主题节变成作者堆砌
- [ ] 缺少主题间的过渡与联系
- [ ] 方法论评述流于表面
- [ ] 研究空白表述含糊（"研究不足"过于笼统）
- [ ] 未明确回应"本研究将做什么"
- [ ] 引用编号位置错误（标点后而非前）
- [ ] 英文文献数量未达 1/3
- [ ] 文献年份超出 2023-2026

---

## 八、最终核查清单

完成综述初稿后，依次核查：

1. [ ] 总字数 ≥ 8000 汉字
2. [ ] 结构完整（引言 + 2-4 主题 + 联系 + 方法 + 空白）
3. [ ] 每节都有比较与评价，无简单罗列
4. [ ] 末尾明确指出 Research Gap
5. [ ] 中英文比例符合要求
6. [ ] 全部脚注对应正文夹注
7. [ ] 所有"作者（年份）"形式正确
8. [ ] 脚注位置在观点最后一字后、标点前
