# 模型评估、修正、中介与调节

## 一、拟合指标

### 报告这一组（标配）

| 指标 | 类型 | 可接受 | 良好 | 说明 |
|---|---|---|---|---|
| **χ²（df, p）** | 绝对 | — | — | **必报，但不作为判定依据** |
| **χ²/df** | 绝对 | < 5 | **< 3** | 样本量敏感度较低 |
| **CFI** | 增值 | ≥ .90 | **≥ .95** | 最常用 |
| **TLI (NNFI)** | 增值 | ≥ .90 | ≥ .95 | 对模型复杂度有惩罚 |
| **IFI** | 增值 | ≥ .90 | ≥ .95 | 可选 |
| **RMSEA** | 绝对 | ≤ .08 | **≤ .06** | 报告 90% CI |
| **SRMR** | 绝对 | ≤ .08 | ≤ .05 | AMOS 需装插件才有 |
| GFI / AGFI | 绝对 | ≥ .90 / ≥ .85 | — | **受样本量影响大，近年不推荐作为主要依据** |

### 关键认知

1. **χ² 显著不等于模型不好。** 样本量大时 χ² 几乎必然显著。**不要因为 p < .05 就说模型被拒绝。**
2. **别只挑好看的报。** CFI + TLI + RMSEA + SRMR + χ²/df 是标配组合，**全都要报**。
3. **Hu & Bentler (1999) 的双指标准则**：CFI ≥ .95 **且** SRMR ≤ .08（或 RMSEA ≤ .06 且 SRMR ≤ .08）。
4. **AMOS 默认不输出 SRMR** —— 需要用 `Plugins → Standardized RMR` 插件（AMOS 自带）。

### 拟合不好怎么办（按优先级）

1. **回到达标预检验** —— 十有八九是数据问题（载荷太低、区分效度不过）
2. 检查**模型设定**是否符合理论
3. 检查是否有 **Heywood case**（负误差方差）
4. **最后**才考虑修正指数

## 二、修正指数 MI —— 最容易翻车的地方

### 规则

| ✅ 可以 | ❌ 不可以 |
|---|---|
| 加**同一因子内部**两个题项的**误差相关** | 跨因子加误差相关 |
| 有理论/措辞依据（题项相似、位置相邻） | 纯粹为了让 RMSEA 掉到 .08 以下 |
| 一次只加一条，重新估计后再看 | 一口气加十几条 |
| 在论文中**如实报告**改了什么、为什么 | 假装模型一次就跑通了 |

### 判定
- MI **> 10** 才值得考虑（有些用 > 4，太宽松）
- 同时看 **Par Change**（参数改变量），太小的不值得加

### 底线

> **一个拟合完美但靠十几条 MI 拗出来的模型，一文不值。**
>
> 审稿人会问：你的理论预测了这些误差相关吗？如果没有，那你在做什么？

**跨因子的误差相关几乎等于承认你的构念不干净**——这时正确的做法是回去修量表，不是加路径。

## 三、中介效应

### 必须用 Bootstrap（Sobel 检验已过时）

**AMOS 设置**：
`Analysis Properties → Bootstrap`
- ☑ Perform bootstrap：**2000**（推荐 5000）
- ☑ **Bias-corrected confidence intervals**：95
- ☑ Percentile confidence intervals（可同时勾）

**AmosEngine**：
```vb
Sem.Bootstrap(5000)
Sem.ConfidenceBC(95)
Sem.Standardized()
```

### 判定

| 效应 | 怎么看 |
|---|---|
| **间接效应** | **95% Bias-corrected CI 不包含 0 → 显著** |
| 直接效应 | 同上 |
| 总效应 | 同上 |

**不要只看 p 值**，Bootstrap 的核心是**置信区间**。

### 中介类型判定

| 间接效应 | 直接效应 | 结论 |
|---|---|---|
| 显著 | 不显著 | **完全中介** |
| 显著 | 显著 | **部分中介** |
| 不显著 | — | 无中介效应 |

> ⚠️ "完全中介 / 部分中介"的提法近年受到批评（直接效应不显著可能只是功效不足）。更稳妥的表述：**"间接效应显著，中介效应成立"**，并报告间接效应占总效应的比例。

### 多重中介
在 AMOS 中需用 **User-defined estimand**（Estimands）自定义每条间接路径，才能得到各自的 CI。

## 四、调节效应

### 方法 A：多群组分析（分类调节变量）

**必须先做测量不变性检验**，否则组间比较无意义：

| 层级 | 约束 | 判定 |
|---|---|---|
| **形态不变性** (Configural) | 无约束，只要求结构相同 | 拟合可接受 |
| **弱不变性** (Metric) | 载荷相等 | **ΔCFI < .01** |
| **强不变性** (Scalar) | 载荷 + 截距相等 | ΔCFI < .01 |
| 严格不变性 | 再加误差方差相等 | 通常不要求 |

> **ΔCFI < .01** 是主流判据（Cheung & Rensvold, 2002）。用 Δχ² 也可以，但样本大时过于敏感。

达到**弱不变性**后，才能比较路径系数：
- 约束模型（路径相等） vs 自由模型
- **Δχ² 显著 → 该路径存在组间差异 → 调节效应成立**

### 方法 B：潜变量交互（连续调节变量）

- **乘积指标法**：先中心化，再构造交互项指标
- 指标多时会爆炸（配对/正交化处理）
- **建议**：连续调节变量在 AMOS 里很痛苦，考虑改用 **PROCESS（显变量）** 或 **Mplus / lavaan（潜变量交互 LMS）**

## 五、竞争模型比较

不要只跑一个模型说"拟合很好"。**跑几个竞争模型做对比**，说服力强得多。

| 比较 | 用什么 |
|---|---|
| 嵌套模型 | **Δχ²(Δdf) 检验** |
| 非嵌套模型 | **AIC / BIC / ECVI**（越小越好） |
| 测量不变性 | **ΔCFI** |

常见的竞争模型：
- 单因子模型 vs 多因子模型（检验区分效度）
- 完全中介 vs 部分中介
- 有无某条路径
