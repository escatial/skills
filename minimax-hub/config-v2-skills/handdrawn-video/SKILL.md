# Handdrawn Video

把简短创意转化为一份可直接复制给视频模型的 prompt，遵循用户原始风格。核心风格：真实生活空间、手机追拍、粗粝二维手绘、连续变形、真实物理接触。

## 处理流程

1. 解析并保留用户明确的模型、时长、画幅、主体、场景和变形路线；`15s/15 秒`、`16：9` 等写法统一为标准格式。
2. 未指定模型时用 MiniMax H3；时长或画幅缺失且会影响结果时，只调用一次 `question`，其他内容自行补全。不得改写用户明确的参数（例如 16:9 不得变成 9:16）。
3. 若用户没有完整变形路线，规划一条“同一手绘实体连续变形”的路线；每次变形都要有中间态，不得瞬移或突然换角色。
4. 为场景补足生活化细节：光线/天气、空间质感、至少 4 个真实道具、动画可接触的表面和环境声音。保留自然凌乱、使用痕迹、轻微污渍、划痕、灰尘和水渍，不要广告式布置或过度整洁。
5. 按时长分成 4—5 个连续时间段：每段只安排一个主要动作或变形；至少 2 个时间段包含拍摄者真实手的好奇互动，结尾留下自然收束或小巧笑点。15 秒可用 `0-3 / 3-6 / 6-10 / 10-13 / 13-15`；12 秒可用 `0-3 / 3-6 / 6-9 / 9-12`。
6. 镜头默认保持连续追拍；如果采用剪辑或多镜头，必须明确写出每个镜头的景别、机位、主体动作、转场和时间段，不得只写“分镜剪辑”。手机质感包括单手拍摄、轻微手抖、追拍滞后、自动对焦犹豫、自动白平衡漂移、曝光波动、局部过曝、运动模糊、暗部自然噪点和手机压缩感；不用稳定云台或摄影棚补光。
7. 写清动画与真人手和物体的接触、遮挡、反射、折射、碰撞、透视和光线关系；动画不能像贴纸一样悬浮。真人手保持未经修饰的真实质感：可见毛孔、皮肤纹理、细小干燥纹、轻微泛红和不均匀肤色。每次真人与手绘实体互动都形成“一方动作 → 另一方反馈 → 镜头跟随”的连续闭环，反馈体现在位置、方向、速度、姿态或情绪变化上。
8. 统一手绘外观：蜡笔/粉笔/彩铅/粉彩/粗笔刷，逐帧重绘感，线条和涂色轻微抖动，柔和微光，不照亮整个实景。颜色、尾迹、运动方向在变形中继承。
9. 声音只写环境声、真实物体声、拍摄者脚步/衣物/呼吸，以及与每次变形同步的柔和手绘音效；默认无背景音乐、旁白和对白。

## 输出格式

先输出一行：`模型，时长，画幅。`
随后只输出一份完整可执行 prompt，按以下顺序组织：

```text
整体影像与场景 → 手机拍摄质感 → 分段动作/变形 → 手绘统一规则 → 真人物理关系 → 负面限制 → 声音设计
```

## 必须避免

3D 卡通、玩偶感、平滑矢量线、均匀霓虹、精致广告布光、稳定云台、跨场景硬切、字幕、标识、巨大眼睛、裂口、尖牙、恐怖威吓、扑袭、突然黑屏、跳吓、物体穿模。

不要解释创作过程，不要重复用户原文；除非存在参数冲突，否则直接给出成稿。
