# premium-product-motion｜高质感产品动态广告

## 1. Skill 定位

**高质感产品动态广告 Skill** 用于为用户提供的产品图、包装图、Logo、产品描述或参考视频，生成 **15 秒以下** 的产品主角型品牌广告短片。

它强调：

- 产品一致性
- 多模态参考角色分配
- 生图层视觉锚定
- 商业摄影质感
- 材质与功能可视化
- AE / Motion Design 风格动态图形
- 品牌广告级产品定版
- 平台画幅适配

一句话判断：

> 如果用户想在 **15 秒以内** 做一条“产品本身”为主角的短广告，通过材质、镜头、动效、卖点视觉化和最后品牌定版完成成片，就进入本 Skill。

## 2. 触发场景

本 Skill 的触发范围收敛为：**15 秒以下、产品为唯一或绝对主角、以广告成片为目标的短视频**。

当用户同时满足以下条件时，触发本 Skill：

1. **时长是 15 秒以下**，或用户表达为“几秒广告 / 10 秒广告 / 15 秒以内 / 短广告 / 社媒短视频广告”；
2. **主体是具体产品**，包括产品图、包装图、Logo、产品描述、SKU 或产品系列；
3. **目标是广告成片**，而不是电商静态图、真人口播带货、官网功能演示或长篇品牌大片；
4. 画面重点围绕产品外观、材质、卖点、成分、功能、包装、动效转场和最终产品定版。

## 4. 核心原则

### 4.1 不把优秀效果归因于长提示词

优秀产品视频通常来自：

```text
高质量产品锚图 + 风格参考图 / 参考视频 + 结构化提示词 + 模型能力
```

其中多模态参考素材往往贡献 50%–70% 的最终质感。提示词负责组织方向、约束一致性、生成镜头逻辑和广告表达。

### 4.2 先判断是否需要生图层锚定

本 Skill 不应直接跳到视频生成。进入视频前，必须判断是否需要先生成静态视觉锚图。

需要先做生图层锚定的情况：

1. 用户没有高质量产品锚图
2. 用户只有文字产品描述
3. 产品材质是核心卖点
4. 科技功能或内部结构是核心卖点
5. 食品饮料 / 护肤成分需要视觉化
6. 多 SKU / 多口味 / 多颜色产品需要系列一致性
7. 需要先确认视觉方向
8. 需要稳定首帧、尾帧或 Hero 定版

### 4.3 产品锚图优先级最高

产品锚图用于锁定：

- 产品外观
- 包装比例
- Logo 位置
- 主材质
- 颜色系统
- 关键识别点

提示词、风格图和参考视频不得覆盖产品锚图中的产品事实。

### 5.1 最小必需输入

至少一个：

- 产品图
- 包装图
- Logo
- 产品实拍图
- 产品渲染图

```text

```

必须提供：

- 产品品类
- 产品名称或品牌名

```text
做一条智能手表广告，品牌叫 AURA，黑色方形表盘，主打 15 天续航和运动健康。
```

如果没有产品锚图，需要提示用户：

```text
没有产品锚图时，产品一致性、Logo 稳定性和包装准确度会弱于有参考图的情况。建议先生成产品 Hero 锚图确认。
```

## 6. 多模态参考角色分配

进入 Skill 后，应先为用户输入的素材分配角色。

### 6.1 产品锚图

用于锁定产品身份。优先级最高。

贡献：

- 产品外形
- 包装结构
- Logo 位置
- 材质
- 主色
- 识别点

规则：

```text
产品锚图不得被风格参考或文字风格词覆盖。
```

### 6.2 Logo 图

用于：

- 结尾品牌定版
- 包装识别
- 画面角标
- 字体风格参考

注意：如果用户要求 Logo 绝对准确，建议在后期叠加，不完全依赖视频模型生成。

### 6.3 风格参考图

迁移：

- 光影
- 构图
- 色调
- 材质质感
- 摄影风格
- 空间氛围
- 高级感

不迁移：

- 参考图里的产品身份
- 参考图里的 Logo
- 参考图里的文字
- 参考图里的具体品牌

### 6.4 参考视频

迁移：

- 镜头节奏
- 运动结构
- 转场方式
- 快切密度
- 产品出现方式
- 结尾定版节奏

不迁移，除非用户明确要求：

- 原产品
- 原品牌
- 原文字
- 原 Logo
- 原包装信息

### 6.5 文字描述

用于补齐：

- 产品品类
- 产品定位
- 卖点
- 创意方向
- 视觉母题
- 文字包装
- 音频方向

## 7. 两级问询分流

如果用户没有明确说明方向，必须执行两个中文问询。

### 问询 1：你想重点突出产品的哪一面？

A. **质感高级**
强调材质、光影、包装、奢华感、产品高级感。适合美妆、香氛、奢侈品、精品包装、高端生活方式产品。

B. **科技功能**
强调结构、性能、功能、精密制造、未来感。适合耳机、手表、智能眼镜、手机、AI 硬件、游戏掌机、电竞鼠标等。

C. **成分 / 口感 / 能量**
强调液体、食材、口味、冰爽、泡沫、果实、能量爆发。适合饮料、食品、啤酒、甜品、果汁、功能饮料。

D. **生活方式 / 使用场景**
强调产品如何进入真实生活、办公、旅行、社交或户外场景。适合日用品、家居产品、便携设备、生活方式品牌。

E. **多卖点快切 / 系列矩阵**
强调多 SKU、多颜色、多口味、多功能、多镜头快切。适合系列产品、促销主推、社媒投放和多卖点广告。

---

### 问询 2：你希望最终成片更像哪一种？

A. **高端品牌定版广告**
产品是唯一主角，画面克制高级，结尾形成稳定完整的品牌定版，适合官网、发布会、品牌页和招商展示。

B. **社媒快节奏动态广告**
节奏更快、镜头更多、转场更强，第一眼更抓人，适合抖音、小红书、视频号、朋友圈广告等短视频平台。

C. **新品发布揭示短片**
从局部、暗场、结构或材质开始，逐步揭示产品全貌，强调登场感、发布感和新品首发气质。

D. **材质氛围短片**
更重视材质、光影、触感和气味联想，镜头偏微距、慢节奏，适合美妆、香氛、奢侈品、食品、酒饮、家居等质感型产品。

E. **卖点视觉解释短片**
每个镜头对应一个核心卖点，可加入简短中文卖点字幕，用结构拆解、能量流、成分流动、对比画面等方式解释产品优势。


只问两级问询，不额外扩展问卷。

## 10. 生图层视觉锚定模块

### 10.1 产品 Hero 定版图

适用：产品外观不明确、需要首尾帧、需要视频结尾定版。

```text
[产品] 的高质感产品广告 Hero 定版图，产品居中，背景干净高级，产品外观清晰稳定，材质真实，光影精致，结尾定版感强，适合作为视频生成的产品锚图。
```

### 10.2 材质微距图

适用：香水、美妆、护肤、包袋、手表、耳机等质感优先产品。

```text
[产品关键部位] 的极端微距商业摄影，清晰展示 [材质/纹理/Logo/水滴/金属/玻璃]，浅景深，精准轮廓光，真实反射，高级产品广告质感。
```

### 10.3 功能拆解图

适用：科技硬件、汽车、耳机、手表、AI 设备、电竞鼠标。

```text
[产品] 的高端科技产品广告图，产品以爆炸图方式分层悬浮，内部核心部件、芯片、外壳和功能模块沿中心轴展开，周围有极简 HUD 标注和发光线条，暗调科技摄影棚，精密工业设计质感。
```

### 10.4 成分 / 口味爆发图

适用：饮料、食品、啤酒、冰淇淋、护肤成分、功能饮料。

```text
[产品] 位于画面中心，周围环绕 [配料/水果/冰块/泡沫/碎屑]，形成向心式动态冻结构图，高速摄影感，液体飞溅清晰锐利，背景色与口味匹配，食品饮料广告级高饱和视觉。
```

### 10.5 多 SKU 矩阵图

适用：系列产品、多颜色、多口味、多型号。

```text
[产品系列] 的多 SKU 商业广告合集图，多个产品按扇形 / 九宫格 / 横向序列方式整齐排列，每个 SKU 对应独立色彩和口味元素，背景有重复文字图案或色块分区，最终形成完整品牌系列定版。
```

### 10.6 生活方式场景图

适用：便携产品、包袋、运动科技、办公产品、家居小物。

```text
[人物/手部/使用场景] 与 [产品] 同框的高端生活方式广告图，产品清晰可见，背景为现代建筑 / 办公桌 / 户外环境，画面真实、干净、有品牌广告质感。
```

## 11. 生图视觉技法库

在编译生图或视频关键帧 Prompt 时，可按产品类型调用以下技法。

### 11.0 技法库调用规则

第 11 章不是独立输出，也不是额外生成步骤，而是服务于本 Skill 的三个关键生成节点：

#### A. 无产品场景美学锚点图

在生成无产品场景美学锚点图前，必须根据以下信息从第 11 章选择 **2–4 个视觉技法**：

- 产品品类
- 产品卖点
- 用户选择的产品重点
- 用户选择的成片形态
- 已有产品锚图中的可见识别点

调用方式：

```text
产品类型 / 卖点方向 → 选择 2–4 个第 11 章视觉技法 → 编译为无产品场景锚点图 Prompt
```

场景锚点图必须体现所选技法的空间、材质、光影、成分、结构或广告摄影气质，但必须保持：

```text
无产品包装、无产品瓶身、无品牌 Logo、无可读文字、无随机商标。
```

示例：

```text
零食 / 番茄肉酱味 / 社媒快节奏
→ 调用 11.4 液体与食品成分 + 11.5 材质与微距 + 11.6 光影与背景空间
→ 生成番茄酱飞溅、玉米角碎屑、高速棚拍、强层次动势的无产品场景锚点图。
```

#### B. 九宫格故事板

在生成九宫格故事板时，必须把已选视觉技法拆入 9 个关键帧中。

调用方式：

```text
产品锚图 + 无产品场景锚点图 + 已选第 11 章技法
→ 生成 3x3 九宫格故事板
```

九宫格中的每一格不能只是“好看的画面”，至少要承担以下一种广告功能：

- 开场钩子
- 产品局部显现
- 产品完整出现
- 材质 / 成分 / 功能视觉化
- 口味 / 功效 / 结构记忆点
- 转场节点
- 中段视觉高潮
- 卖点文字或图形信息层
- 最终产品 Hero 定版

规则：

```text
第 11 章决定关键帧“看起来像什么”；第 18 / 19 章决定这些关键帧“如何动起来、如何转场”。
```

#### C. H3 视频 Prompt 编译

在最终 H3 视频生成阶段，不直接复制第 11 章的技法词条，而是将技法转译为：

- 镜头动作
- 材质变化
- 产品出现方式
- 空间层次变化
- 成分 / 功能可视化事件
- 光影运动
- 转场触发元素

调用方式：

```text
九宫格故事板 + 已选第 11 章视觉技法 + 第 18 / 19 章动态转场模块
→ 编译 H3 三段式视频 Prompt
```

示例：

```text
11.4 液体与食品成分
不应在 H3 Prompt 中只写成“high-speed frozen liquid splash”，
而应转译为“浓稠番茄酱从画面侧面飞溅到镜头前，短暂铺满画面，再从酱汁纹理中擦出下一镜头”。
```

```text
11.1 透明介质与折射
不应只写成“transparent glass panels”，
而应转译为“半透明水膜掠过瓶身边缘，折射标签与背景植物影子，并作为柔性遮挡进入下一镜头”。
```

## 12. 视频提示词编译结构

生成视频前，应按以下结构编译 Prompt：

### 12.1 基础信息段

```text
生成一支 [时长]、[画幅比例] 的高质感产品广告短片。
产品为：[产品名称 / 产品品类 / 产品描述]。
品牌名称为：[品牌名]。
产品定位为：[产品定位]。
目标观感为：[高端 / 年轻 / 科技 / 奢华 / 清爽 / 专业 / 有趣]。
```

### 12.2 非普通广告声明

```text
这不是普通产品展示、不是电商货架视频、不是简单产品旋转、不是廉价 CG，也不是随机炫技短片。整支影片应融合商业产品摄影、电影级镜头语言、Cinema 4D 材质动画、After Effects 高级动态图形和品牌广告级视觉设计。
```

### 12.3 核心视觉母题

```text
核心创意是：[根据产品品类与问询答案生成一句视觉母题]。
所有镜头、动效、材质变化和转场都必须围绕这个母题展开，不能出现与产品无关的随机特效。
```

示例：

- 香水：香气正在重新塑造空间。
- 精华：一滴精华让干燥材质恢复水光与弹性。
- 游戏掌机：产品屏幕成为进入多个游戏世界的入口。
- 智能眼镜：镜片让现实世界被理解、记录和增强。
- 积木：每一次拼搭动作都会触发一组高级动态图形反馈。
- 饮料：每一种口味都释放出独立的色彩、成分和能量世界。

### 12.4 产品一致性段

```text
产品外观、包装结构、Logo 位置、颜色系统、主要材质、关键识别元素必须在所有镜头中保持一致。不得随机改变产品比例、增减部件、漂移标识、生成无关文字、改变包装信息或替换成类似产品。
```

### 12.5 多模态参考段

```text
产品锚图用于锁定产品外观、包装比例、Logo、材质和关键识别点；风格参考图只迁移光影、构图、材质表现和商业摄影气质；参考视频只迁移镜头节奏、转场结构、运动方式和成片编辑逻辑，不保留原产品、原品牌或原文字，除非用户明确要求。
```

### 12.6 时间轴段

默认 15 秒五段式：

```text
0–3 秒：[产品钩子 / 局部显现 / 品类识别]
3–6 秒：[产品世界建立 / 第一层卖点]
6–9 秒：[核心动效 / 功能或材质视觉化]
9–12 秒：[视觉高潮 / 多卖点 / 场景变化]
12–15 秒：[产品完整定版 / 品牌锁定]
```

社媒快节奏 15 秒结构：

```text
0–2 秒：[强钩子 / 大标题 / 快速产品出现]
2–5 秒：[第一产品或第一卖点]
5–8 秒：[第二产品或第二卖点]
8–11 秒：[第三产品或高潮切换]
11–14 秒：[合集 / CTA / 多产品阵列]
14–15 秒：[品牌最终定格]
```

### 12.7 文字包装段

默认：

```text
文字只使用短词组，不出现长段落，不出现乱码，不出现随机字母，不出现水印，不出现底部外挂字幕。文字必须作为品牌广告信息层或空间动态图形出现，与产品、镜头运动和画面留白发生关系。
```

若用户不需要文字：

```text
除最后品牌名或 Logo 外，全片不出现任何可读文字。
```

若用户需要卖点文字：

```text
每个卖点只使用 1 个短标题或 1 组极简词组，字体为现代无衬线，白色或品牌色，排版干净，不能遮挡产品。
```

### 12.8 音频段

```text
无旁白。音乐采用与产品气质匹配的高级广告配乐。根据镜头加入克制的 whoosh、机械声、液体声、包装弹跳声、粒子声、转场音效和最终品牌提示音。音效必须服务产品动作与镜头节奏。
```

### 12.9 禁止项段

```text
禁止低清廉价渲染、禁止产品变形、禁止 Logo 漂移、禁止文字乱码、禁止无关水印、禁止随机 UI、禁止背景杂乱、禁止产品被粒子遮挡、禁止镜头抖动、禁止转场拖沓、禁止与产品无关的炫技特效。
```

## 14. 执行路径判断

### 14.1 可直接生成

满足以下条件时可直接生成：

- 只需要 1 条视频
- 时长明确
- 产品锚点明确
- 不需要复杂拼接
- 不需要多段分别审核
- 不需要多版本多比例输出
- 不需要额外配音 / 字幕 / BGM 后期合成

### 14.2 应进入小型 workflow

以下情况应进入工作流：

- 多条视频共享同一产品身份
- 需要先生成产品锚图再生成视频
- 需要多镜头分段生成后拼接
- 需要 BGM、音效、字幕、Logo 后期合成
- 需要多平台多比例版本
- 需要用户确认分镜后再生成
- 参考视频替换复杂，涉及多产品、多文字、多段运动结构

## 15. 推荐工作流

```text
1. 素材检查
   - 是否有产品图 / 包装图 / Logo / 参考视频
   - 是否需要保持参考视频结构
   - 是否有品牌名、产品名、卖点、平台比例、时长

2. 多模态角色分配
   - 产品锚图：锁定产品身份
   - 风格图：迁移视觉气质
   - 参考视频：迁移运动结构
   - Logo 图：锁定品牌标识
   - 文字描述：补充卖点和创意方向

3. 两级问询
   - 问询 1：产品重点
   - 问询 2：成片形态

4. 判断是否需要生图层锚定
   - 需要则先生成产品 Hero / 材质微距 / 拆解图 / 成分爆发图 / 多 SKU 矩阵图
   - 用户确认关键图后进入视频

5. 生成创意方案
   - 核心视觉母题
   - 产品一致性锁
   - 视觉世界
   - 时间轴分镜
   - 文字包装规则
   - 动效 / 转场规则
   - 音频风格
   - 禁止项

6. 用户确认或直接生成
   - 简单单条视频：直接生成
   - 多段 / 多 SKU / 多比例 / 后期合成：进入小型 workflow

7. 输出
   - 6–15 秒产品广告视频
   - 可选 9:16 / 16:9 / 1:1 / 4:5
   - 可选无字幕 / 短卖点文字 / 品牌定版
```

## 16. 质量检查标准

输出前检查：

1. 产品是否始终是主角
2. 产品外观是否稳定
3. 包装比例是否一致
4. Logo / 品牌信息是否尽量稳定
5. 动效是否围绕产品发生
6. 是否没有随机炫技
7. 材质是否可信
8. 镜头节奏是否符合所选成片形态
9. 结尾是否有明确产品定版
10. 文字是否短、清楚、不过量
11. 是否没有乱码、水印、旧品牌残留
12. 参考视频是否只迁移结构，不误保留原产品

**高质感产品动态广告 Skill**：面向用户提供的产品图、包装图、Logo、产品描述或参考视频，快速生成 **15 秒以下** 产品主角型品牌广告。它通过两级问询确认产品表达重点和成片形态，自动分配多模态参考角色，并在必要时先用生图层生成关键视觉锚图，再进入视频生成，最终输出适合品牌发布、社媒投放、产品展示或新品预热的高完成度产品广告短片。

## 18. Motion & Transition Module｜转场与节奏模块

本模块用于解决视频生成时“画面有内容但变化平淡”的问题。视频 Prompt 不能只描述每个镜头里有什么，还必须明确：

- 镜头之间如何切换
- 转场由什么画面元素触发
- 节奏如何跟音乐落点匹配
- 什么时候快、什么时候停
- 哪些元素负责遮挡、擦镜、撞击、爆发、收束

### 18.1 总原则

```text
视频不是若干静态关键帧的平滑播放，而是由明确的视觉事件、转场机制和节拍变化组成的动态广告。每个镜头切换都应由产品、材质、配料、液体、光线、文字或图形元素自然触发。
```

生成视频 Prompt 时，必须根据用户选择的成片形态加入对应转场策略。

---

### 18.2 按成片形态选择转场策略

#### A. 高端品牌定版广告

适合：奢侈品、美妆、香氛、高端科技、精品包装。

节奏关键词：

- 慢推
- 慢拉
- 光线扫过
- 材质显现
- 透明介质渐变
- 缓慢遮挡转场
- 定版减速

Prompt 规则：

```text
使用克制、高级、缓慢的画面变化。镜头之间通过光线扫过、透明材质遮挡、浅景深焦点转移、丝绸或水膜轻柔掠过完成转场。避免频繁快切，避免社媒花字撞击。最终 Hero 定版时镜头明显减速并稳定停住。
```

可用转场：

- 光扫转场
- 水膜柔性遮挡
- 透明玻璃折射转场
- 丝绸掠过遮挡
- 焦点转移切换
- 缓慢推拉定版

---

#### B. 材质氛围短片

适合：护肤、香氛、酒饮、精品食品、材质型产品。

节奏关键词：

- 微距连续运动
- 液体慢流
- 光影呼吸
- 材质遮挡
- 柔焦过渡

Prompt 规则：

```text
使用舒缓但不静止的材质运动。镜头之间通过液体流动、精华滴落、水膜包裹、丝绸褶皱、玻璃折射或焦外光斑完成柔性转场。节奏安静，变化细腻，重点是触感、气味感和材质记忆点。
```

可用转场：

- 液体慢流 wipe
- 精华滴落 match cut
- 丝绸褶皱遮挡
- 微距焦点转移
- 水面涟漪扩散转场

---

#### C. 新品发布揭示短片

适合：科技产品、智能硬件、新品首发、概念产品。

节奏关键词：

- 暗场显现
- 结构展开
- 光扫揭示
- HUD 扫描
- Match cut
- 由神秘到完整

Prompt 规则：

```text
视频节奏从暗场、局部、结构细节逐步推进到完整产品揭示。镜头之间通过光线扫过、零件展开、HUD 扫描线、形状匹配和结构层切换完成转场。前半段保持神秘，后半段逐步加速，最终形成完整产品定版。
```

可用转场：

- 暗场光扫显现
- 结构爆炸图展开
- HUD 扫描切换
- 零件遮挡转场
- 形状匹配转场

---

#### D. 卖点视觉解释短片

适合：科技功能、护肤功效、食品成分、运动性能。

节奏关键词：

- 一个卖点一个视觉事件
- 功能图形转场
- 细线标注生长
- 结构层展开
- 对比切换

Prompt 规则：

```text
每个卖点必须对应一个明确的视觉事件。镜头之间通过功能图形、细线标注、环形能量线、成分流动、结构层展开或对比画面完成转场。不要只平移镜头重复展示产品，每一段都要增加新的卖点信息。
```

可用转场：

- 细线标注生长转场
- 环形屏障线扩散
- 功能图标擦出
- 成分流动遮挡
- 结构层展开切换
- Before / After 对比切换

---

#### E. 社媒快节奏动态广告

适合：食品、饮料、零食、年轻彩妆、多 SKU、促销、新品快消。

节奏关键词：

- 冲击硬切
- 液体 wipe
- 前景擦镜
- 包装弹跳
- 花字撞击
- 图案闪切
- Match cut
- 快进快出
- 定版急停

Prompt 规则：

```text
采用节拍同步快切，不使用平滑无力的普通淡入淡出。每 1.2–1.8 秒出现一个新的视觉事件，镜头切换必须由画面元素触发：液体遮挡镜头、产品或配料擦过前景、包装弹跳入场、大花字撞击、图案闪切或形状匹配。动作曲线为快进快出，冲击瞬间短促有力，最终 Hero 定版时突然减速稳定。
```

可用转场：

- 液体遮挡转场
- 前景擦镜转场
- 爆发式硬切
- 包装弹跳入场
- 大花字撞击
- 图案闪切
- 形状匹配转场
- 三层空间前后穿插

## 19. 常用转场技法 Prompt 片段

### 19.1 液体遮挡转场 / Liquid or Sauce Wipe

适合：食品、饮料、护肤、美妆。

```text
使用液体遮挡式转场：浓稠液体从画面侧面飞溅到镜头前，短暂铺满整个画面，再从液体纹理中擦出下一镜头。
```

食品版：

```text
使用番茄酱遮挡式转场：浓稠红色酱汁从画面侧面飞溅到镜头前，短暂铺满整个画面，再从酱汁纹理中擦出下一镜头。
```

护肤版：

```text
使用透明水膜柔性转场：半透明水膜轻柔掠过镜头前景，短暂折射画面，再从水膜波纹中显现下一镜头。
```

---

### 19.2 前景擦镜转场 / Foreground Whip Pass

```text
使用前景擦镜转场：一个与产品相关的主体高速掠过镜头前景，短暂占满画面，作为鞭甩式遮挡切入下一镜头。
```

零食版：

```text
一个中空锥形玉米角从前景高速旋转擦过镜头，短暂占满画面，作为鞭甩式转场切入下一镜头。
```

科技版：

```text
一个分离的金属结构件或发光环从前景高速掠过，遮挡镜头并切入下一段产品结构画面。
```

---

### 19.3 Match Cut 形状匹配转场

```text
使用形状匹配转场：前一镜头中的几何形态与后一镜头中的产品图案或结构形态精准衔接，让切换自然且高级。
```

零食版：

```text
中空玉米角的圆形开口切入包装上的玉米角图案，圆形番茄切入包装上的番茄图案。
```

美妆版：

```text
一滴精华液的圆形高光切入瓶身上的圆形反光，水膜弧线切入产品外轮廓。
```

科技版：

```text
圆形声波环切入耳机单元，芯片网格切入产品内部结构层。
```

---

### 19.4 爆发式硬切 / Burst Smash Cut

```text
使用爆发式硬切：产品相关元素在画面中央瞬间向外爆开，伴随短促冲击闪光，直接切入下一关键画面。
```

食品版：

```text
番茄酱、碎屑和玉米角向外爆开，伴随短促冲击闪光，直接切入下一关键画面。
```

饮料版：

```text
冰块、水花和水果切片向外爆开，形成高能量冲击硬切。
```

---

### 19.5 包装弹跳入场 / Pack Bounce Reveal

适合：食品、饮料、社媒快消。

```text
包装从画面下方弹跳入场，产生轻微压缩和回弹，带动产品配料、碎屑或液滴向外飞散。
```

---

### 19.6 大花字撞击 / Typography Impact Hit

只在用户选择社媒快节奏、年轻食品、饮料、彩妆、多 SKU 或促销方向时使用。

```text
3D贴纸感大字以弹性撞击方式冲入画面，撞出配料、液体和碎屑飞溅，随后产品从文字层中穿出。
```

规则：

```text
大花字只出现一次，不遮挡产品核心信息，不生成随机额外文字。
```

---

### 19.7 三层空间前后穿插 / Layered Depth Transition

```text
保持三层空间结构：前景飞过的产品相关元素，中景产品主体，背景液体、光线、图形或色块。每次转场都由前景元素自然遮挡并揭示下一镜头。
```

---

### 19.8 图案闪切 / Pattern Flash Transition

适合：食品、饮料、波普社媒广告。

```text
插入极短图案闪切帧，由产品轮廓、配料图形、液滴、碎屑和品牌色块组成，持续极短时间，作为节拍点上的视觉冲击。
```

---

### 19.9 快进快出运动曲线 / Fast-in Fast-out Motion Curve

```text
使用快进快出的运动曲线：转场时爆发式加速，视觉撞击瞬间短促有力，随后快速进入下一镜头；最终 Hero 定版时突然减速并稳定停住。
```

## 20. 九宫格故事板到视频的动态编译规则

九宫格故事板确认后，生成视频 Prompt 时必须加入动态编译，不允许仅按 1–9 格静态复述。

### 20.1 编译方式

```text
@产品图 是产品身份锚点。
@九宫格故事板 是镜头顺序、视觉风格和关键帧锚点。
视频生成时，将九宫格压缩成有节拍的动态广告：相邻格之间必须通过明确转场机制衔接，而不是普通淡入淡出。
```

### 20.2 社媒快节奏广告建议节奏

15 秒社媒广告建议 8–10 个视觉事件：

```text
0.0–1.2s：强钩子爆发
1.2–2.4s：前景擦镜或液体 wipe 到产品局部
2.4–3.8s：包装弹跳完整出现
3.8–5.0s：match cut 到产品/食材微距
5.0–6.4s：卖点动效爆发
6.4–7.8s：大花字撞击或功能图形冲击
7.8–9.5s：产品从图形层穿出
9.5–11.2s：配料/结构/液体环绕高潮
11.2–13.2s：最终视觉能量收束
13.2–15.0s：突然减速，Hero 定版
```

### 20.3 高端定版广告建议节奏

15 秒高端广告建议 5–7 个视觉事件：

```text
0–3s：材质或局部显现
3–6s：光线扫过产品结构
6–9s：核心材质 / 卖点温和视觉化
9–12s：产品完整进入高级场景
12–15s：减速并形成 Hero 定版
```

## 21. Typography Moment Rule｜文字记忆点规则

九宫格第 5 格不是固定大花字，而是“中段记忆点”。是否出现大花字由用户选择的成片形态决定。

- **高端品牌定版广告**：不使用大花字，使用材质高潮、光影记忆点、极简留白或小型品牌级词组。
- **材质氛围短片**：不使用大花字，使用微距材质、液体、光影或纯视觉记忆点。
- **新品发布揭示短片**：可使用克制的巨型无衬线字、半透明文字或空间文字，但不使用装饰花字。
- **卖点视觉解释短片**：使用功能标注、细线说明、极短卖点词或图形符号，不使用装饰花字。
- **社媒快节奏动态广告**：可使用大花字、3D 泡泡字、贴纸字、波普字效和高冲击标题。

若文字风格会明显影响成片，应询问用户：

```text
这条片子是否需要明显的大字视觉？
A. 不需要，保持高级克制
B. 需要少量极简短词
C. 需要卖点标注
D. 需要社媒感大花字
```

## 22. 妙脆角 / 零食类社媒广告动态模板

当用户选择：

```text
产品重点 = 成分 / 口感 / 能量
成片形态 = 社媒快节奏动态广告
```

且产品为零食、饮料、快消食品时，可使用以下动态模板：

```text
全片采用社媒快节奏广告剪辑，不使用平滑无力的普通淡入淡出。镜头之间必须由画面元素触发转场：番茄酱遮挡镜头形成 sauce wipe，玉米角高速擦过前景形成 whip-pass，包装袋弹跳入场形成 pack bounce reveal，大花字以撞击方式出现并带出酱汁飞溅，番茄和玉米角图形用于 match cut。每 1.2–1.8 秒出现一个新的视觉事件，动作曲线为快进快出，冲击瞬间短促有力，最终 Hero 定版时突然减速稳定。保持三层空间结构：前景飞过的玉米角，中景包装袋，背景番茄酱飞溅和橙黄红波普色块。
```

## 23. H3 Multi-Reference Compile Rules｜H3 多参考编译规范

本 Skill 的最终视频阶段默认面向 MiniMax H3 多模态参考模式进行编译。进入 H3 前，必须把所有参考素材的职责写清楚，避免产品锚图、场景锚点、故事板、节奏参考互相污染。

### 23.1 推荐 H3 多参考上传顺序

```text
@图片1：产品锚图
用于锁定产品外观、包装结构、Logo、标签文字、材质、比例和关键识别点。它是产品身份最高优先级素材。

@图片2：无产品场景美学锚点图
用于锁定空间、背景、材质组合、光影方式、色彩系统、氛围和高级审美。它不提供产品身份，不保留其中的虚构产品、Logo 或文字。

@图片3：九宫格故事板
用于锁定镜头顺序、关键帧、构图节奏、卖点视觉化、转场节点、文字记忆点和最终 Hero 定版。按从左到右、从上到下顺序读取。

@图片4：Logo / 片尾标准字（可选）
仅在用户需要准确片尾品牌定版、独立 Logo 露出或后期叠加时使用。

@视频1：节奏 / 转场参考（可选）
只迁移剪辑节奏、运镜速度、转场方式或运动结构，不迁移原产品、原品牌、原文字。

@音频1：音乐节拍 / 音效参考（可选）
只迁移节拍、氛围、声音质感或品牌声音方向。音频不能单独输入，必须同时有图片或视频。
```

### 23.2 素材职责优先级

当多个参考素材发生冲突时，按以下优先级处理：

```text
用户明确指令 > 产品锚图 > 九宫格故事板 > 场景美学锚点图 > 节奏参考视频 > 泛化文字风格词
```

具体规则：

- 产品外观、包装、Logo、标签、比例以产品锚图为准。
- 场景锚点只提供美学，不改变产品。
- 九宫格故事板提供镜头顺序和关键帧，不覆盖产品锚图事实。
- 参考视频只提供运动结构和剪辑节奏，不保留原品牌或原产品。
- 风格词只能补充，不得改写素材事实。

---

## 24. H3 素材体检规则

进入 H3 生成前，执行以下检查：

### 24.1 产品锚图检查

```text
产品图是否能看清完整外观、包装结构、Logo、标签、材质、关键识别点和比例？
```

若产品图存在明显遮挡、反光、变形或文字不可读，应提示：

```text
当前产品图可用作基础锚图，但包装文字或局部结构可能不够稳定。建议补充一张平整正面产品图或独立 Logo 图。
```

### 24.2 场景美学锚点检查

```text
场景锚点是否无产品、无包装、无随机文字、无 Logo？是否只提供空间、光影、材质、色彩和氛围？
```

若场景锚点中出现虚构产品，应在 H3 Prompt 中明确：

```text
@图片2 只作为场景和风格参考，不保留其中的参考产品身份、包装或文字。
```

### 24.3 九宫格故事板检查

```text
九宫格是否包含：开场氛围、产品局部、完整出现、卖点视觉化、中段记忆点、第二卖点、场景融合、视觉高潮、最终定版？
```

若九宫格缺少转场节点，应在视频 Prompt 中补充动态编译，而不是静态复述九格。

### 24.4 参考素材数量检查

H3 多模态参考限制：

```text
图片最多 9 张；视频最多 3 段；音频最多 3 段；混合文件最多 12 个。
参考视频单段 2–15 秒，视频总参考时长不超过 15 秒。
参考音频单段 2–15 秒，音频总参考时长不超过 15 秒。
音频不能单独输入，必须同时有图片或视频。
```

### 24.5 弱相关素材剔除

```text
只上传承担明确职责的参考素材。弱相关图片不要凑数，否则会稀释产品一致性、场景风格和镜头节奏。
```

## 25. H3 Direct Three-Part Prompt｜H3 三段式视频 Prompt

最终提交给 H3 的视频 Prompt 推荐采用官方三段式结构：

```text
一、参考素材说明
二、核心创意
三、画面过程说明
```

### 25.1 一、参考素材说明

写清每个参考素材的职责和边界。

模板：

```text
一、参考素材说明：
@图片1 是产品锚图，用于锁定 [产品外观、包装、Logo、标签、材质、比例、关键识别点]。所有镜头中产品身份以 @图片1 为准。
@图片2 是无产品场景美学锚点图，用于锁定 [空间、背景、材质、光影、色彩、氛围]，不保留其中任何虚构产品、Logo 或文字。
@图片3 是九宫格故事板，按从左到右、从上到下顺序作为镜头节奏、关键帧、转场节点、卖点视觉化和最终定版参考。
```

如果有视频或音频参考：

```text
@视频1 只参考剪辑节奏、运镜速度和转场方式，不保留原产品、原品牌或原文字。
@音频1 只参考音乐节拍、情绪和声音质感。
```

---

### 25.2 二、核心创意

写清成片类型、时长、比例、视觉母题和节奏风格。

模板：

```text
二、核心创意：
这是一条 [时长] 秒 [画幅] 的 [成片形态] 产品广告。产品重点是 [产品重点]。核心视觉母题是：[一句视觉母题]。全片保持 [风格关键词]，产品始终是唯一主角。视频节奏为 [舒缓高级 / 逐步揭示 / 卖点解释 / 社媒快切]，镜头变化必须服务产品和卖点，不出现无关场景或随机炫技。
```

示例：

```text
这是一条 15 秒 16:9 的社媒快节奏零食广告。产品重点是番茄肉酱风味、酥脆中空玉米角和口感能量。核心视觉母题是：番茄酱爆发唤醒中空玉米角的浓郁脆感。全片保持高饱和橙黄红波普食品广告风格，产品包装始终是视觉主角。
```

---

### 25.3 三、画面过程说明

按时间推进写画面，不只复述镜头内容，还必须写明转场机制、节奏曲线和声音。

模板：

```text
三、画面过程说明：
0.0–1.2s：[强钩子 / 场景建立 / 视觉爆点]，转场方式：[液体 wipe / 光扫 / 前景擦镜 / match cut]，声音：[具体音效]。
1.2–2.4s：[产品局部或第一次出现]，转场方式：[具体机制]，声音：[具体音效]。
...
最后 2 秒：[Hero 定版]，所有动态元素减速并收束，产品完整清晰停在画面中心，声音自然收尾。
```

## 26. H3 复杂度控制规则

### 26.1 不要把 15 秒写成不可执行动作堆叠

```text
复杂创意优先减少镜头数量或合并视觉事件，不要把每个镜头写成多个互相竞争的动作。
```

### 26.2 社媒快节奏广告的复杂度

15 秒社媒广告可以有 8–10 个视觉事件，但每个事件只负责一个主要变化：

- 爆发
- 擦镜
- 包装入场
- 微距展示
- 花字撞击
- 产品穿出
- 配料环绕
- Hero 定版

不要让一个事件同时承担太多内容。

### 26.3 高端定版广告的复杂度

15 秒高端广告建议 5–7 个视觉事件：

- 局部显现
- 材质微距
- 产品进入场景
- 卖点温和可视化
- 光影高潮
- Hero 定版

不使用过多快切。

## 27. H3 声音设计规则

H3 支持生成原生声音时，Prompt 中必须写清声音。除非用户明确要求静音，否则不要默认无声。

### 27.1 食品 / 零食 / 饮料社媒广告

```text
动感节拍音乐 + whoosh + 酱汁飞溅声 + 酥脆咔嚓声 + 包装弹跳声 + 短促品牌收束音。
```

### 27.2 高端护肤 / 美妆 / 香氛广告

```text
轻柔高级音乐 + 水滴声 + 玻璃/水膜轻响 + 丝绸或亚麻轻动声 + 克制品牌提示音。
```

### 27.3 科技产品 / 智能硬件广告

```text
低频脉冲音乐 + 金属触感音 + HUD 扫描声 + 能量线流动声 + 精准品牌提示音。
```

### 27.4 生活方式产品广告

```text
自然环境声 + 轻柔动作声 + 包装或手部触碰声 + 温和背景音乐。
```

### 27.5 声音约束

```text
声音必须服务画面动作和转场节奏。不要加入无关旁白、随机对白或不符合产品气质的音乐。
```

提交 H3 前检查：

```text

10. 是否控制在 H3 可执行复杂度内？
```
