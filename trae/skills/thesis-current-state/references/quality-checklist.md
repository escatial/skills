# 质量自检清单

每次交付"现状"章节时，按本清单逐项自检并随交付物一同附上。

## 一、数据真实性（最重要）

- [ ] 核心数字均来自公开可追溯来源（年报/招股书/官网/统计/学术数据库）
- [ ] 每个数字带"截至 YYYY-MM"或"XXXX 年报告期"截止时间
- [ ] 数字交叉核验：核心数字至少 2 个来源一致
- [ ] 估算/推算的数据明确标注"约""大致"
- [ ] 未披露/找不到来源的数据明确标"未披露/待核实"，不编造
- [ ] 数据未做无依据的四舍五入

## 二、匿名化（若用户要求）

- [ ] 公司全称/股票代码已删除或替换为代号
- [ ] 法人代表/注册地址/注册资本/园区等已脱敏
- [ ] 子公司名替换为"全资/控股[业务]子公司"
- [ ] 关键客户名替换为"国内某[行业]头部品牌商"
- [ ] 海外客户名替换为地区性描述
- [ ] 供应商名替换为"国内某[材料]主要供应商"
- [ ] 数字化服务商名替换为"国内某[服务类型]服务商"
- [ ] 自主品牌名替换为代号
- [ ] 国家级行业标准编号可保留
- [ ] 通用产品/技术名称（如 SAP、MES、ISO 9001）可保留

## 三、学术规范

- [ ] 第三人称、客观陈述，无"我认为""我们觉得"
- [ ] 引述数据带来源词（"根据""依据""公开披露"）
- [ ] 章节首段用 1-2 句主题句统领，不堆套话
- [ ] 段落首行缩进 2 字符（或 Word 样式设置）
- [ ] 标题层级一致（一级/二级/三级）
- [ ] 中英文混排用宋体 + Times New Roman
- [ ] 章节末尾留 1 句过渡句
- [ ] 关键术语首次出现给出全称（如"产品生命周期管理（PLM）"）

## 四、去 AI 痕迹

- [ ] 删除"较为""相对""较为完整""整体上呈现出""需要指出的是"等套话
- [ ] 删除负面对比（"不仅…而且…"）
- [ ] 减少 em-dash 连用，改用"和""以及"";"
- [ ] 用具体数据替代模糊表述（"显著""明显"等需有数字支撑）
- [ ] 删除"自 XXX 以来"等时间副词堆砌
- [ ] 段尾不留空话总结
- [ ] 删除"可作为""有助于""能够实现"等公文腔
- [ ] 删除"虚拟范围"（"从 X 到 Y"无意义罗列）
- [ ] 删除促销/宣传语（"一站式""标杆""领军""行业领先"等）
- [ ] 删除"标题式三段"（避免每段都用"第一/第二/第三"强行三段）

## 五、段落质量

- [ ] 每段遵循"论点—证据—小结"三段式
- [ ] 段长 80-200 字，避免过短（<50 字）或过长（>300 字）
- [ ] 同一段落只表达一个论点
- [ ] 段间有过渡，不直接跳切
- [ ] 数据描述具体（数字+单位+时间），避免"大量""很多"等模糊量词

## 六、结构合规

- [ ] 章节小节数 3-5 个（不含 3.1 公司概况）
- [ ] 同级小节结构对称（都用"流程"或都用"环节"）
- [ ] 子标题动词具体（"X 流程"优于"X 情况"）
- [ ] 图表（如有）编号完整（图 3-1、表 3-1）
- [ ] 图表下方有图注/表注

## 自检报告模板

```markdown
## 质量自检报告

✅ 数据真实性：核心数字 X 项，均已核实来源；2 项待用户提供。
✅ 匿名化：已按映射表脱敏；保留公开可查的行业标准编号。
✅ 学术规范：第三人称、来源词齐、段落格式合规。
✅ 去AI痕迹：删除套话 X 处、负面对比 Y 处。
✅ 段落质量：平均段长 X 字，符合论点-证据-小结结构。

⚠️ 需用户进一步提供/确认：
- [待核实数据1]
- [待核实数据2]
```
