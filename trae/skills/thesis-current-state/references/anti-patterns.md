# 论文「现状」章节反模式清单

> 这些写法在 AI 生成文本中频繁出现，也是指导老师最容易标红的地方。每次写作前必查。

## 一、套话与模糊副词

| 反模式 | 正确替代 |
|--------|----------|
| 较为完整 | 给出具体维度（"覆盖 X、Y、Z 三个维度"）|
| 较强的制造能力 | 给出具体数据（"年产 6.72 亿支牙刷"）|
| 整体上呈现出 | 删除，改为事实陈述 |
| 较为明显 | 给出具体数据 |
| 相对成熟 | 给出技术/标准维度（"通过 ISO 9001 认证"）|
| 需要指出的是 | 删除，直接陈述 |
| 众所周知 | 删除 |
| 总的来说 | 删除，章节末句用事实替代 |

## 二、负面对比 / 二元结构

| 反模式 | 正确替代 |
|--------|----------|
| 不仅…而且… | 拆成两句陈述 |
| 一方面…另一方面… | 拆成两段 |
| 既…又… | 拆成两句 |
| 在巩固 X 的同时，持续加大 Y 的投入 | 拆成两句先后写 |

## 三、宣传 / 营销 / 套话

| 反模式 | 正确替代 |
|--------|----------|
| 一站式服务 | "覆盖 X、Y、Z 全产品线" |
| 标杆工厂 | 给出具体称号与年份（"2021 年获批江苏省工业互联网标杆工厂"）|
| 行业领先 | 用市场份额/排名/出口量等客观指标 |
| 领军企业 | 给出具体称号与年份 |
| 焕新 / 赋能 / 助力 | 删除或用"推动""支持"等中性词 |
| 焕新升级 | "完成升级" |
| 打造数字化工厂 | "已部署 X、Y、Z 系统" |

## 四、模糊时间副词

| 反模式 | 正确替代 |
|--------|----------|
| 近年来 | "2020—2025 年期间" |
| 当前 | "截至 2025 年末" |
| 目前 | "截至 2025 年报告期" |
| 现阶段 | 同上 |
| 自…以来 | 删掉，用具体年份范围 |

## 五、虚拟范围

| 反模式 | 正确替代 |
|--------|----------|
| 从 X 到 Y，从 A 到 B | 列举具体项目 |
| 涉及 X、Y、Z 等多个方面 | 列出 3-5 个具体方面 |
| 涵盖…等 | 列出全部 3-5 个 |

## 六、em-dash 滥用

中文论文慎用 em-dash（——），最多每段 1 个，且必须成对使用或单用。常见滥用：

❌ "B 公司——作为国内日化领军企业——在 X 方面有优势"  
✅ "B 公司在 X 方面有优势（依据 Y）"

## 七、空话段尾

不要写"综上/总之/总而言之"等总结句，章节末段直接点出"事实 + 引出下章"。

❌ "综上所述，B 公司在生产管理数字化转型方面已取得一定成效，但仍面临诸多挑战。"

✅ "B 公司的物料配送流程在跨基地调拨、跨业务线共用物料的协同方面仍较多依赖人工协调，WMS 系统对全局库存可视化和最优调拨决策的支持能力有待加强。"

## 八、标题式三段

避免每段都写"第一…第二…第三…"：

❌ "第一，X；第二，Y；第三，Z。"

✅ 直接拆成 3 个段落，每段主题句+证据。短句用分号合并。

## 九、"标杆式"形容词

| 反模式 | 正确替代 |
|--------|----------|
| 取得显著成效 | 给出具体数据 |
| 实现大幅增长 | 给出增长率 |
| 持续优化 | 给出具体改造内容 |
| 不断完善 | 给出具体措施 |

## 十、Q&A 痕迹

LLM 容易写出"用户问什么 / 答什么"的痕迹。论文不能有这种对话语气。

❌ "那么，这些系统具体是如何协同的呢？答案是…"

✅ "在 SRM 系统的支持下，公司与国内某数字化采购服务商合作搭建了一体化数字采购管理平台，实现线上寻源。"
