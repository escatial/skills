## 设计思维

在编码之前，理解上下文并承诺一个大胆的美学方向：
- **目的**：这个界面解决什么问题？谁使用它？
- **基调**：选择一个极端：极致简约、极繁主义混乱、复古未来主义、有机/自然、奢华/精致、玩趣/玩具-like、编辑/杂志、粗野主义/原始、装饰艺术/几何、柔和/粉彩、工业/实用等。有很多风格可以选择。用这些作为灵感，但设计一个真正符合美学方向的。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：什么让这令人难忘？人们会记住的一件事是什么？

**关键**：选择一个清晰的概念方向并精确执行它。大胆的极繁主义和精炼的极简主义都能工作——关键是有意性，而不是强度。

然后实现可工作的代码（HTML/CSS/JS、React、Vue等）：
- 生产级且功能性
- 视觉震撼且令人难忘
- 具有清晰美学观点的凝聚性
- 在每个细节上精心打磨

## 前端美学指南

专注于：
- **排版**：选择美丽、独特、有趣的字体。避免通用字体如Arial和Inter；相反，选择提升前端美学的独特选择；意想不到的、有个性的字体选择。将独特的展示字体与精炼的正文字体配对。
- **颜色与主题**：承诺一个凝聚的美学。使用CSS变量保持一致性。主色调搭配尖锐的强调色优于胆怯的、均匀分布的调色板。
- **动效**：使用动画实现效果和微交互。优先为HTML使用纯CSS解决方案。在可用时为React使用Motion库。专注于高impact时刻：一个精心编排的页面加载with交错揭示（animation-delay）比零散的微交互创造更多愉悦。使用滚动触发和悬停状态带来惊喜。
- **空间构图**：意想不到的布局。不对称。重叠。对角线流动。打破网格的元素。慷慨的负空间 OR 受控密度。
- **背景与视觉细节**：创造氛围和深度，而不是默认为纯色。添加与整体美学匹配的上下文效果和纹理。应用创意形式，如渐变网格、噪声纹理、几何图案、分层透明度、戏剧性阴影、装饰边框、自定义光标和颗粒叠加。

永远不要使用通用的AI生成美学，如过度使用的字体系列（Inter、Roboto、Arial、系统字体）、老套的配色方案（尤其是白底上的紫色渐变）、可预测的布局和组件模式，以及缺乏特定上下文特征的模板化设计。

创意诠释并做出感觉真正为上下文设计 的意想不到的选择。每个设计都不一样。在浅色和深色主题、不同字体、不同美学之间变化。永远不要在代际之间收敛于常见选择（例如Space Grotesk）。

**重要**：将实现复杂度与美学愿景匹配。极繁设计需要复杂的代码with广泛的动画和效果。极简或精炼的设计需要克制、精确、仔细关注间距、排版和微妙的细节。优雅来自于很好地执行愿景。

## 既有组件库项目的换肤重构

给已上线、基于组件库（Element Plus / Ant Design 等）的项目去 AI 味换装时，优先走「变量覆盖 + 版式重排」而非推倒重写：

- **变量整体换肤**：组件库都暴露主题 CSS 变量（如 Element Plus 的 `--el-color-*`、`--el-border-radius-*`、`--el-font-family`）。在一个独立主题文件里整套覆盖，全站按钮/表格/表单/弹窗一次落色，业务模板不必逐个改。
- **⚠️ 特异性坑（实测踩过）**：组件库变量定义在 `:root` 上（类级特异性 0,1,0）。用自己的 `html {}`（标签级 0,0,1）去覆盖会被原值压住、静默失效——必须同样写 `:root`，并确保主题文件在组件库 CSS **之后** import，靠加载顺序取胜。改完用 `getComputedStyle(document.documentElement).getPropertyValue('--el-color-primary')` 实测验证是否生效，不要只看页面感觉。
- **中文项目字体路线**：展示字体用 Georgia/衬线中文（思源宋体经 `@fontsource/*` 本地打包，免 CDN、国内可用），数字开 `font-variant-numeric: oldstyle-nums` 提升质感；提示性小字可用楷体制造"批注"感；正文保持黑体系保证可读性。
- **重构纪律**：业务逻辑（stores、api、事件处理）一行不动，只动 template 版式与样式；满屏内联样式收编为 scoped class；模板化 emoji 按钮、白卡片堆叠、默认蓝是"AI 痕迹"三大来源，优先清除。
