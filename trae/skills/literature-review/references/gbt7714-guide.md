# GB/T 7714-2015 引用格式详解

本参考文件详解 GB/T 7714-2015《信息与文献 参考文献著录规则》的核心规范，供撰写文献综述时构造脚注内容使用。

## 一、文献类型标识（前置单字母）

| 文献类型 | 标识 | 示例 |
|---------|------|------|
| 期刊论文 | J | 数字化转型研究[J] |
| 专著 | M | 数字化转型研究[M] |
| 学位论文 | D | 数字化转型研究[D] |
| 会议论文 | C | 数字化转型研究[C] |
| 报纸文章 | N | 数字化转型研究[N] |
| 专利 | P | 数字化转型研究[P] |
| 电子文献 | EB | 数字化转型研究[EB/OL] |

> 本技能仅使用 `[J]`（期刊论文）。其他类型文献必须排除。

---

## 二、核心格式模板

### 2.1 中文期刊论文

**格式**：
```
作者. 题名[J]. 刊名, 出版年, 卷(期): 起止页码.
```

**示例**：
```
李明华, 王晓东. 供应链数字化转型对企业绩效的影响研究[J]. 管理世界, 2024, 40(3): 120-135.
```

**字段说明**：

| 字段 | 规范 |
|------|------|
| 作者 | 多人之间用逗号分隔；3 人及以上可列 3 人后加"等"或"et al." |
| 题名 | 完整题名，不省略 |
| 刊名 | 使用全称或标准缩写；不使用书名号 |
| 出版年 | 仅写年份数字 |
| 卷(期) | 卷号后用括号注明期号；无卷号时只写期号 |
| 页码 | 起止页码用短横线 `-` 连接 |

### 2.2 英文期刊论文

**格式**：
```
Author. Title[J]. Journal Name, Year, Vol(No): Pages.
```

**示例**：
```
Smith J A, Jones B C. Digital Transformation and Supply Chain Performance: Evidence from Manufacturing Firms[J]. Journal of Operations Management, 2024, 45(3): 230-251.
```

**字段说明**：

| 字段 | 规范 |
|------|------|
| Author | 姓在前名缩写在后，逗号分隔；超过 3 人可列 3 人后加"et al." |
| Title | 首字母大写，其余按原期刊风格 |
| Journal Name | 使用斜体；可使用标准缩写 |
| Year | 仅写年份数字 |
| Vol(No) | 卷(期)；使用阿拉伯数字 |
| Pages | 起止页码 |

### 2.3 英文作者姓名格式

| 作者数 | 格式 |
|--------|------|
| 1 人 | `Smith J A` |
| 2 人 | `Smith J A, Jones B C` |
| 3 人 | `Smith J A, Jones B C, Brown D E` |
| 4+ 人 | `Smith J A, Jones B C, Brown D E, et al.` |

**名字缩写规则**：
- 名缩写保留首字母大写
- 多字名每字都缩写：`John Andrew Smith` → `Smith J A`
- 复姓保留：`Van Der Berg` → `Van Der Berg J`

## 三、特殊场景处理

### 3.1 同一作者多篇文献

脚注中分别独立著录，正文用"作者（年份，年份）"形式区分：

```
正文：李明华（2023，2024）从不同角度研究了数字化转型问题。

脚注 1：李明华. 数字化转型的内涵界定[J]. 中国工业经济, 2023, (5): 50-65.
脚注 2：李明华. 数字化转型对企业绩效的传导机制研究[J]. 管理世界, 2024, 40(2): 88-104.
```

### 3.2 同年多篇文献

用 a, b, c 区分：

```
正文：张三（2024a, 2024b）...
```

### 3.3 引用期刊无卷号

仅有期号时，省略卷号：

```
张三. 论数字化转型的路径选择[J]. 管理科学学报, 2024, (8): 45-60.
```

### 3.4 页码跨期

连续多页：
```
2024, 40(3): 120-135.
```

跨期连续：
```
2024, 40(3): 120-135, 137-142.
```

## 四、常见错误对照表

| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| 标识错误 | 题名[M] | 题名[J] |
| 缺卷期 | 2024: 120-135 | 2024, 40(3): 120-135 |
| 页码用波浪号 | 2024: 120~135 | 2024: 120-135 |
| 作者顺序 | J. A. Smith | Smith J A |
| 刊名带书名号 | 《管理世界》 | 管理世界 |
| 缺逗号分隔 | 李明华 王晓东 | 李明华, 王晓东 |

## 五、脚注排版规范

### 5.1 字体字号

- 中文字体：宋体
- 英文字体：Times New Roman
- 字号：六号（7.5pt）

### 5.2 编号格式

- Word 自动连续编号（1, 2, 3, ...）
- 上标显示

### 5.3 脚注位置

> 脚注编号置于「该学者观点最后一个字之后，句中标点之前」

```
李明华（2024）认为供应链数字化转型能显著提升运营效率¹，但在...
                     ↑ 编号位置                    ↑ 标点位置
```

## 六、完整示例

### 中文脚注示例

```
¹ 李明华, 王晓东. 供应链数字化转型对企业绩效的影响研究[J]. 管理世界, 2024, 40(3): 120-135.

² 张三, 李四. 人工智能技术应用研究[J]. 中国工业经济, 2023, (10): 88-104.

³ 王五等. 数字化转型的路径选择[J]. 管理科学学报, 2024, (8): 45-60.
```

### 英文脚注示例

```
⁴ Smith J A, Jones B C. Digital Transformation and Supply Chain Performance: Evidence from Manufacturing Firms[J]. Journal of Operations Management, 2024, 45(3): 230-251.

⁵ Johnson M R. The Impact of AI on Organizational Agility[J]. Strategic Management Journal, 2023, 44(8): 1500-1525.

⁶ Brown D E et al. A Meta-Analysis of Digital Transformation Effects[J]. MIS Quarterly, 2024, 48(2): 567-590.
```

### 中英文混合段落示例

> 数字化转型已成为管理学研究的热点议题。Smith（2024）通过实证研究发现¹，组织敏捷性对绩效具有正向影响。李明华（2024）从中国情境出发²，进一步证实了这一结论在新兴市场中的适用性。然而，王五等（2023）指出³，二者关系可能受到行业特征的调节。

## 七、核查清单

撰写完所有脚注后，逐项核查：

- [ ] 所有脚注均为 `[J]` 标识
- [ ] 所有年份在 2023-2026 范围内
- [ ] 所有页码使用短横线 `-`
- [ ] 中文文献用中文标点（逗号`，`、句号`。`）
- [ ] 英文文献用英文标点（逗号`,`、句号`.`）
- [ ] 作者超过 3 人使用"等"或"et al."
- [ ] 卷(期)完整，无缺失
- [ ] 期刊名无书名号
