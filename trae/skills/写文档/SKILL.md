## 触发条件

**触发关键词**：
- 写文档、创建文档、起草文档
- 提案、技术规格、规格说明
- 决策文档、决策记录
- 文档协作、内容写作

**触发场景**：
- 用户要求\"帮我写一份文档\"
- 用户要求\"创建一个提案\"
- 用户要求\"起草技术规格\"
- 用户要求\"写决策文档\"
- 用户要求\"协作写作\"

**不触发**：
- 用户只是要求一般聊天（非文档写作）"
---

### 1. 理解需求

首先，明确文档的目标和受众：
- 文档的目的是什么？
- 谁是目标读者？
- 需要涵盖哪些关键点？
- 有什么特定的格式要求吗？

### 2. 结构规划

根据文档类型，建议适当的结构：

**技术规格：**
- 概述
- 功能需求
- 非功能需求
- 设计考虑
- API接口
- 安全性
- 性能
- 部署

**提案：**
- 执行摘要
- 问题陈述
- 解决方案
- 成本分析
- 时间线
- 风险
- 结论

**决策文档：**
- 背景
- 选项
- 推荐
- 理由
- 风险
- 依赖

### 3. 内容协作

与用户迭代：
- 起草初稿
- 提供改进建议
- 完善细节
- 确保一致性

### 4. 审阅与定稿

帮助用户：
- 检查完整性
- 验证准确性
- 确保清晰度
- 格式一致性
