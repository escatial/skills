# CNKI 文献检索 Skill

## 描述

批量在中国知网(CNKI)检索学术文献，自动提取 GB/T 7714-2015 格式引文、摘要、关键词等元数据。支持单篇检索和批量检索，输出 Markdown 或 JSON 格式。

## 触发条件

当用户表达以下意图时触发：
- "检索知网文献"
- "批量获取文献引文"
- "文献综述核查"
- "获取 GB/T 7714 引文"
- "查文献摘要"
- "整理参考文献"
- 包含"知网"+"引文"/"摘要"/"文献"

## 参数

### 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| titles | list[string] | 是 | - | 文献标题列表 |
| output_format | string | 否 | markdown | 输出格式：markdown/json |
| delay | number | 否 | 3 | 检索间隔秒数 |

### 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| articles | list[ArticleInfo] | 文献信息列表 |
| failed | list[string] | 检索失败的标题列表 |

## 工作流程

### 步骤 1：解析用户输入

从用户消息中提取文献标题列表：
- 识别编号列表（1. 2. 3.）
- 识别换行分隔的标题
- 识别引号包裹的标题

### 步骤 2：批量检索文献

对每篇文献执行：
1. 访问 `https://kns.cnki.net/kns8s/defaultresult/index`
2. 在 `#txt_search` 输入标题
3. 触发搜索（JS 事件触发 `.search-btn`）
4. 等待 3 秒加载结果
5. 查找标题链接并获取详情页 URL
6. 访问详情页并等待 3 秒
7. 提取：摘要、关键词、作者、期刊、年份、卷期、页码、DOI

### 步骤 3：生成引文

按 GB/T 7714-2015 格式生成：
```
[序号] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.
```

### 步骤 4：输出结果

根据 `output_format` 输出：
- **markdown**：格式化的文献列表，含引文和摘要
- **json**：结构化数据，便于程序处理

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 验证码弹窗 | 提示用户手动完成验证 |
| 文献未找到 | 记录到 failed 列表，继续下一篇 |
| 页面加载超时 | 重试 1 次，仍失败则记录 |
| 信息提取失败 | 标记为"待补充"，不中断流程 |

## 示例

### 示例 1：单篇检索

**用户输入**：
```
请检索知网文献"基于DBR的再制造系统缓冲设置模型研究"
```

**执行流程**：
1. 解析 titles = ["基于DBR的再制造系统缓冲设置模型研究"]
2. 访问知网搜索页
3. 输入标题并搜索
4. 进入详情页提取信息
5. 输出 GB/T 7714 引文和摘要

**预期输出**：
```markdown
## [1] 基于DBR的再制造系统缓冲设置模型研究

**作者：** 陈伟达，林晶晶
**期刊：** 科研管理
**年份：** 2010
**卷(期)：** 31(05)
**页码：** 108-115
**DOI：** 10.19571/j.cnki.1000-2995.2010.05.014

### GB/T 7714-2015 引文
[1] 陈伟达, 林晶晶. 基于DBR的再制造系统缓冲设置模型研究[J]. 科研管理, 2010, 31(05): 108-115.

### 摘要
DBR生产计划与控制技术是制约因素理论(TOC)应用于...

**关键词：** DBR；瓶颈缓冲；回流缓冲；出货缓冲；再制造系统
```

### 示例 2：批量检索

**用户输入**：
```
请批量检索以下文献：
1. 基于DBR的再制造系统缓冲设置模型研究
2. 再制造系统生产计划优化方法
3. 约束理论在制造系统中的应用
```

**执行流程**：
1. 解析 titles = ["基于DBR的再制造系统缓冲设置模型研究", "再制造系统生产计划优化方法", "约束理论在制造系统中的应用"]
2. 循环执行单篇检索流程
3. 每篇间隔 3 秒
4. 汇总输出所有结果

## 限制说明

1. **验证码**：知网可能弹出安全验证，需人工干预
2. **频率限制**：建议每次不超过 10 篇，间隔 3 秒以上
3. **网络依赖**：需要稳定的网络连接
4. **信息准确性**：自动提取需人工核对
