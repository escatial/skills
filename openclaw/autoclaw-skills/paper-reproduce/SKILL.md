# Paper Reproduce - 论文复现技能

## 工作流程（自动执行，无需用户干预）

用户上传PDF -> 解析全文 -> 结构化提取 -> 代码实现 -> 实验验证 -> 结论对比 -> 报告

## Step 1: 论文解析

使用 pdf 工具提取论文全文文字。如果效果差，回退到 exec 调用 pdfplumber/PyMuPDF。

提取以下内容并结构化：
- 标题、作者、年份、会议/期刊
- 研究问题与背景动机
- 模型架构（核心模块、完整流程）
- 创新点（主要贡献，3-5条）
- 数学公式（目标函数、损失函数、核心算法步骤）
- 实验设置（数据集、评估指标、硬件环境）
- 超参数（学习率、batch size、epoch等）
- 主要结论（论文报告的核心结果）

注意：如果论文是启发式算法（遗传算法、粒子群等）或博弈论（演化博弈、主从博弈），重点提取：算法步骤、参数设置、博弈模型假设、均衡条件等。

## Step 2: 代码实现

根据论文类型选择实现路径：

### 视觉模型（CNN、ViT、GAN 等）
- 框架：PyTorch
- 结构：模型定义 -> 数据加载（CIFAR-10/ImageNet）-> 训练循环 -> 评估

### NLP/大模型（Transformer、BERT、LLM 等）
- 框架：PyTorch + HuggingFace Transformers
- 结构：模型定义 -> 数据加载 -> 预训练/微调流程

### 启发式算法（GA、PSO、ACO 等）
- 框架：NumPy（纯 Python 实现）
- 结构：算法编码 -> 初始化 -> 适应度评估 -> 选择/交叉/变异 -> 终止判断
- 数据集：经典 benchmark 函数（如 Sphere、Rosenbrock）或实际优化问题

### 博弈论模型（演化博弈、主从博弈）
- 框架：NumPy + SciPy
- 结构：博弈模型定义 -> 收益矩阵/效用函数 -> 均衡求解 -> 敏感性分析

## Step 3: 实验验证

自动执行以下步骤：
1. 用论文建议的公开数据集运行代码
2. 记录训练曲线、收敛性、最终指标
3. 将结果与论文数据进行对比
4. 如有差异，分析原因并调整代码
5. 如仍不一致，标记为无法完全复现并说明原因

原则：不展示中间过程，只展示最终结论。原论文有问题时指出并修正。

## Step 4: 输出格式

最终只向用户报告：
1. 复现结论：✅ 与原论文结论一致 / ⚠️ 部分一致（说明差异）/ ❌ 无法复现（说明原因）
2. 原因分析：代码问题 or 论文问题
3. 最终代码：完整可运行的 Python 代码文件路径

## 代码文件输出

所有代码保存到工作区 paper_reproduce_output/ 目录，文件名格式：{论文缩写}_{模型类型}_{日期}.py
例如：yolov1_cvpr2016.py、ga_tsp_20260414.py

## 关键原则

- 用户不需要干预任何步骤，全程自动完成
- 不展示实验过程细节，只给最终结论
- 代码必须包含详细注释，说明每一步对应论文的哪个部分/公式
